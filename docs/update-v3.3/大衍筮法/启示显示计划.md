### 二、主程序（严格按“先总纲、再全量六爻”输出）

```text
主程序 开始:
  
  // 1. 用户起卦，拿到数据
  当前主卦 = 从卦库中取出(用户摇出的主卦ID)
  当前变卦 = 从卦库中取出(用户摇出的变卦ID)
  当前动爻列表 = 用户摇出的动爻数组  // 例：[1, 3] 代表初爻、三爻动
  
  // 2. 调用合解引擎（计算体用生克、趋势差值等）
  运算结果 = 合解引擎(当前主卦, 当前变卦, 当前动爻列表)
  
  // 3. 生成最终展示文本（分三块）
  
  // ----- 第一块：主变卦基础信息 -----
  左边显示本卦，右边显示变卦。用好看的规整的方式绘画，不要使用——和- -这种丑陋的方法。
  本卦下方显示：当前主卦.上卦+" "+当前主卦.上卦五行
  本卦再下方显示：当前主卦.下卦+" "+当前主卦.下卦五行
  变卦下方显示：当前变卦.上卦+" "+当前变卦.上卦五行
  变卦再下方显示：当前变卦.下卦+" "+当前变卦.下卦五行
  输出 "【能量趋势】" + 运算结果.能量流向 + "，" + 运算结果.趋势描述
  
  // ----- 第二块：本卦总纲（整体介绍） -----
  输出 "【卦象总纲】" + 当前主卦.卦象总纲
  
  // ----- 第三块：完整六爻启示（全部列出，动爻打星号） -----
  输出 "【六爻精解】（★为动爻，为重点关注位）"
  循环 序号 从 0 到 5:  // 对应初爻到上爻
    动爻标记 = 如果 (序号 + 1) 在 当前动爻列表 中，则为 " ★" 否则 ""
    输出 "  " + 当前主卦.六爻启示[序号] + 动爻标记
  
  // ----- 第四块：变卦指向性总结（补足大局观） -----
  输出 "【变卦指向】" + "变卦为" + 当前变卦.卦名 + "，提示最终外部环境将趋于" + 当前变卦.趋势属性 + "，建议结合上述动爻焦点，权衡进退。"
  
主程序 结束
```

### 三、配套的合解引擎（与之前一致，确保主函数变量有来处）

```text
函数 合解引擎(主卦, 变卦, 动爻列表):
  
  // 体用生克
  体五行 = 主卦.下卦五行 
  用五行 = 变卦.上卦五行 
  
  如果 用五行 生 体五行 -> 能量流向 = "外力助我"
  如果 用五行 克 体五行 -> 能量流向 = "外力制我"
  如果 体五行 生 用五行 -> 能量流向 = "我在付出"
  如果 体五行 克 用五行 -> 能量流向 = "我在掌控"
  否则 -> 能量流向 = "内外同步"
  
  // 趋势演算（差值法生成好转或转坏）
  差值 = 变卦.盛衰系数 - 主卦.盛衰系数
  如果 差值 >= 5 -> 趋势描述 = "大幅好转，由阴转阳"
  如果 差值 >= 1 且 < 5 -> 趋势描述 = "缓慢上升，渐入佳境"
  如果 差值 == 0 -> 趋势描述 = "维持原状，以静制动"
  如果 差值 <= -1 且 > -5 -> 趋势描述 = "缓慢下滑，小有损耗"
  如果 差值 <= -5 -> 趋势描述 = "急转直下，由盛转衰"
  
  返回 { 能量流向, 趋势描述, 差值, 动爻列表 }
```
