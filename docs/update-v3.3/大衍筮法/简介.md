# 大衍筮法 简介

## 概述

大衍筮法（又称揲蓍法）出自《周易·系辞上传》，是最古老的周易起卦方法。以 50 根蓍草模拟天地运行，经过 18 次演变得出六十四卦中的一卦。

> "大衍之数五十，其用四十有九。分而为二以象两，挂一以象三，揲之以四以象四时，归奇于扐以象闰。"

## 操作流程

1. 50 根策 → 取 1 根为太极 → 49 根参与演算
2. 每 3 变得出 1 爻（6/7/8/9）
3. 6 爻 × 3 变 = 18 变 → 得出本卦
4. 变爻（6 老阴、9 老阳）阴阳互变 → 得出变卦

## 四营（每变四步）

| 步骤 | 名称 | 操作 |
|------|------|------|
| ① | 分二 | 49 根策随机分左右两堆 |
| ② | 挂一 | 从右堆取 1 根竖起 |
| ③ | 揲四 | 左右各自 4 根一组分数，得余数(1-4) |
| ④ | 归奇 | 挂一 + 左余 + 右余 = 5 或 9（第一变）/ 4 或 8 |

## 三变得一爻

| 变次 | 起始策数 | 归奇结果 | 剩余策数 |
|------|---------|---------|---------|
| 第一变 | 49 | 5 或 9 | 44 或 40 |
| 第二变 | 44/40 | 4 或 8 | 40/36/32 |
| 第三变 | 40/36/32 | 4 或 8 | 36/32/28/24 |

第三变剩余 ÷ 4 = **6 老阴 / 7 少阳 / 8 少阴 / 9 老阳**

## 爻值含义

| 值 | 名称 | 符号 | 状态 |
|----|------|------|------|
| 6 | 老阴 | ⚋ × | 变爻（阴变阳） |
| 7 | 少阳 | ⚊ | 静爻 |
| 8 | 少阴 | ⚋ | 静爻 |
| 9 | 老阳 | ⚊ ○ | 变爻（阳变阴） |

## 六十四卦

从初爻（下）到上爻（上），6 条爻线组成一卦。每卦由下卦（内卦）和上卦（外卦）两个三画卦叠成。

八卦对应：☰乾 ☱兑 ☲离 ☳震 ☴巽 ☵坎 ☶艮 ☷坤

## 启示显示（v3.3-15+）

### 综述

占卜完成后，根据摇出的 6 条爻线计算本卦和变卦，展示 4 块内容：

1. **本卦 ｜ 变卦** — 左右双栏，各用 Canvas 绘制六条爻线（阳爻一整条金色圆角线，阴爻中间留缺），下方标注卦名、上卦五行、下卦五行
2. **卦象总纲** — 本卦的整体气场态势描述
3. **六爻精解** — 本卦全部 6 条爻辞，动爻标 ★ 高亮
4. **变卦指向** — 变卦趋势总结

### 数据结构

```
HexagramRevelation       // 一卦的完整启示
├── name: String         // 卦名（"泰"）
├── fullName: String     // 全名（"地天泰"）
├── summary: String      // 卦象总纲
├── prosperity: Int      // 盛衰系数 (-10..+10)
├── trend: String        // 趋势属性（上升/下降/震荡/平稳）
├── lowerTrigram: Trigram // 下卦（内卦）
├── upperTrigram: Trigram // 上卦（外卦）
└── revelations: List<String> // 六爻启示[6]

Trigram                  // 三画卦枚举
├── value: Int           // 伏羲先天序 (0-7)
├── label: String        // 卦名（坤/艮/坎/巽/震/离/兑/乾）
├── element: String      // 五行（金/木/水/火/土）
└── unicode: String      // 符号（☰☱☲☳☴☵☶☷）

IntegrationResult        // 合解引擎结果
├── energyFlow: String   // 能量流向（外力助我/外力制我/我在付出/我在掌控/内外同步）
├── trendDesc: String    // 趋势描述（大幅好转/缓慢上升/维持原状/缓慢下滑/急转直下）
└── diff: Int            // 差值 = 变卦.盛衰系数 - 本卦.盛衰系数
```

### 合解引擎

**体用生克**（五行循环：金→水→木→火→土→金，克为跳一步）：

| 条件 | 能量流向 |
|------|----------|
| 用五行 生 体五行 | 外力助我 |
| 用五行 克 体五行 | 外力制我 |
| 体五行 生 用五行 | 我在付出 |
| 体五行 克 用五行 | 我在掌控 |
| 相同 | 内外同步 |

**趋势演算**（差值 = 变卦.盛衰系数 − 本卦.盛衰系数）：

| 差值 | 趋势描述 |
|------|----------|
| ≥ 5 | 大幅好转，由阴转阳 |
| 1 ~ 4 | 缓慢上升，渐入佳境 |
| 0 | 维持原状，以静制动 |
| -4 ~ -1 | 缓慢下滑，小有损耗 |
| ≤ -5 | 急转直下，由盛转衰 |

### 卦库索引

64 卦按伏羲先天序排列，索引 = 下卦.数值 × 8 + 上卦.数值。从六爻阴阳线查卦：

```kotlin
// 六爻 → 二进制 → 索引（bit0=初爻 … bit5=上爻，1=阳 0=阴）
var binary = 0
for (i in 0..5) if (lines[i]) binary = binary or (1 shl i)
// binary ∈ [0, 63]
```

动爻翻转生成变卦：老阴(6)→阳气，老阳(9)→阴气。

### 性能：load/release 模式

64 卦启示数据（约 50KB）不在 App 启动时加载，生命周期如下：

| 时机 | 操作 |
|------|------|
| 点击"开始占卜" | `HexagramLibrary.ensureLoaded()` — 初始化 64 卦数据 |
| 占卜完成 → 点击"再来一次" | `HexagramLibrary.release()` — 释放卦库，下次使用时重新加载 |
| 离开大衍筮法页面 | `YarrowViewModel.onCleared()` → `release()` — 自动释放 |

> **设计原因**：避免卦库数据在非占卜期间占用内存。64 卦数据虽小（~50KB），但配合 Canvas 位图和策动画内存，整体占卜流程结束后统一释放更干净。
