### 1. PalaceIndex 枚举（六宫索引）

```kotlin
enum class PalaceIndex(val index: Int, val label: String, val shortLabel: String) {
    DA_AN(0, "大安", "安"),
    LIU_LIAN(1, "留连", "连"),
    SU_XI(2, "速喜", "喜"),
    CHI_KOU(3, "赤口", "口"),
    XIAO_JI(4, "小吉", "吉"),
    KONG_WANG(5, "空亡", "亡"),
    ;

    companion object {
        fun fromIndex(index: Int): PalaceIndex =
            entries.first { it.index == (index % 6 + 6) % 6 }
    }
}
```

- `index`：0-5，用于推算算法中的取模运算
- `label`：中文全名
- `shortLabel`：单字简写，用于柱子标签
- `fromIndex()`：安全取模获取枚举（处理负数情况）

     * 根据 24 小时制获取对应时辰

        in 23..23, in 0..0 -> ShiChen.ZI
        in 1..2 -> ShiChen.CHOU
        in 3..4 -> ShiChen.YIN
        in 5..6 -> ShiChen.MAO
        in 7..8 -> ShiChen.CHEN
        in 9..10 -> ShiChen.SI
        in 11..12 -> ShiChen.WU
        in 13..14 -> ShiChen.WEI
        in 15..16 -> ShiChen.SHEN
        in 17..18 -> ShiChen.YOU
        in 19..20 -> ShiChen.XU
        in 21..22 -> ShiChen.HAI

    }
}
