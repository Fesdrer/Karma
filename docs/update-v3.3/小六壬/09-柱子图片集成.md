2. 宫名和六神文本叠加在图片对应区域上方

### 图片加载方式

使用 Android 内置 `BitmapFactory`，不引入第三方图片库：

```kotlin
val context = LocalContext.current
val pillarImage = remember {
    BitmapFactory.decodeResource(context.resources, R.drawable.pillar_bg).asImageBitmap()
}
```

### 图片缩放策略

**Fit width（适配宽度）**：图片宽度撑满 Canvas，高度等比缩放并垂直居中。

```
scale        = canvasWidth / 1535
scaledH      = 2620 * scale
imgOffsetY   = (canvasHeight - scaledH) / 2
```

在 1224×2700 的屏幕上：
- 图片显示为 1224 × 2088
- 上下各留 ~306px 黑边

### 宫位坐标映射

从图片像素坐标 → Canvas 坐标：

```kotlin
canvasX = imgX * scale
canvasY = imgY * scale + imgOffsetY
```

#### 3. DrawScope 内 — 新增图片绘制常量

```kotlin
// 图片常量
val IMG_W = 1535f
val IMG_H = 2620f

// 适配宽度的缩放
val scale = size.width / IMG_W
val scaledH = IMG_H * scale
val imgOffsetY = (size.height - scaledH) / 2f

// 绘制图片作为背景
drawImage(
    image = pillarImage,
    dstOffset = IntOffset(0, imgOffsetY.toInt()),
    dstSize = IntSize(size.width.toInt(), scaledH.toInt()),
)
```

#### 4. 更新 PalacePosition 计算

替换原基于 `baseY`/`segmentHeight`/`arcOffset` 的计算：

```kotlin
// 图片坐标 → Canvas 坐标
fun mapToCanvas(imgX: Float, imgY: Float) = Offset(imgX * scale, imgY * scale + imgOffsetY)

val pillarCx = floatArrayOf(346f, 763f, 1179f)   // 三柱中心 X
val upperCy = 1124f                                // 上三段中心 Y
val lowerCy = 1608.5f                              // 下三段中心 Y

val positions = listOf(
    PalacePosition(0, mapToCanvas(pillarCx[0], lowerCy)),
    PalacePosition(1, mapToCanvas(pillarCx[0], upperCy)),
    PalacePosition(2, mapToCanvas(pillarCx[1], upperCy)),
    PalacePosition(3, mapToCanvas(pillarCx[2], upperCy)),
    PalacePosition(4, mapToCanvas(pillarCx[2], lowerCy)),
    PalacePosition(5, mapToCanvas(pillarCx[1], lowerCy)),
)
```

**注意：** 移除了原中柱的 `arcOffset` 偏移（速喜/空亡不再上下偏移），因为图片中三柱布局是平的。
