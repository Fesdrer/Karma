### 1. 模式切换 Toggle

```kotlin
@Composable
private fun InputModeToggle(
    currentMode: InputMode,
    onModeChanged: (InputMode) -> Unit,
) {
    Row(
        modifier = Modifier
            .clip(RoundedCornerShape(12.dp))
            .background(Color(0xFF1a1a3e))  // ScoreBtnBg
            .border(1.dp, Color(0xFF334444), RoundedCornerShape(12.dp)),
    ) {
        ToggleOption("传统农历", InputMode.TRADITIONAL, currentMode, onModeChanged)
        ToggleOption("任意数字", InputMode.ARBITRARY, currentMode, onModeChanged)
    }
}
```

选中状态：金色背景（0xFFb8860b）+ 白色文字
未选中状态：透明背景 + 灰色文字（0xFF666666）

private fun ArbitraryInputs(
