# 小六壬动画：金色丝线 → 移动光点 + 虚幻拖尾

## Context

当前 XiaoLiuRenThreadCanvas 使用 4 层贝塞尔曲线绘制静态金线，视觉效果不够灵动。用户要求改为**移动的金黄色明亮光点**，留下**不断变窄消失的虚幻轨迹**，整体动画连续流畅。

修改范围：仅 [XiaoLiuRenThreadCanvas.kt](app/src/main/java/com/example/karma/ui/divination/components/XiaoLiuRenThreadCanvas.kt)，ViewModel 和 Screen 层不变。

## 设计方案

### 核心思路

```
光点沿路径移动 → 每帧记录位置到环形缓冲区 → 绘制拖尾
                                             ↓
                              拖尾从光点宽度渐变到0，alpha从1渐变到0
```

### 数据结构变更

| 旧 | 新 |
|---|---|
| `TrailParticle`（随机粒子） | `TrailPoint(x, y, time)` 环形缓冲区 |
| `Random(42)` | 去掉，无需随机 |
| `mutableListOf<TrailParticle>()` | `ArrayDeque<TrailPoint>(maxSize=40)` |

### 绘制变更

| 旧函数 | 处理方式 |
|---|---|
| `drawSegmentThreads()`（贝塞尔曲线×4层） | **删除** |
| `spawnParticle()` + `updateParticles()`（粒子） | **删除** |
| 绘制已完成段 + 当前段 | **替换为**：计算光点当前坐标 → 记录到缓冲区 → 绘制拖尾 → 绘制光点 |

### 光点绘制

光点由三层组成（从外到内）：
1. **外层光晕**：半径 16dp，alpha 0.15，金色 `#FFD700`
2. **中层辉光**：半径 8dp，alpha 0.45，金色
3. **内核亮点**：半径 3dp，alpha 0.9，亮金色（偏白）

光点始终在最前方（最后绘制，覆盖拖尾）。

### 拖尾绘制

- 缓冲区存储最近 40 个位置（约 0.67 秒 @60fps）
- 从光点位置向尾部遍历，逐段绘制线段
- 每段线段的 **宽度** = `baseWidth * (1 - t)^2`（t 从 0→1，尾部→头部）
  - `baseWidth = 5dp`，尾部宽度趋近 0
- 每段线段的 **alpha** = `baseAlpha * (1 - t)^1.5`
  - `baseAlpha = 0.6`，尾部 alpha 趋近 0
- 拖尾也加一层很淡的外发光（宽度×3, alpha 更低）

### 暂停阶段处理

MONTH_PAUSE / DAY_PAUSE 期间光点停在原位，但帧循环继续运行（持续记录相同位置到缓冲区），拖尾会逐渐缩短/消失——因为新记录的同一位置会慢慢"推出"旧位置，产生拖尾消散的视觉效果。

### 结果发光阶段（RESULT_GLOW）

- 光点停在最终宫位，保持闪烁（通过正弦调制光点大小和 alpha）
- 拖尾继续消散（不再有新位置进入缓冲区，旧位置逐渐被推出）
- 宫位上的结果脉冲光晕保留（当前代码的发光逻辑）

### 动画帧循环

保持现有的 `LaunchedEffect` + `delay(16)` + `System.nanoTime()` 结构不变，阶段切换逻辑不变。只改 Canvas 绘制块的内容。

## 文件变更

**修改 1 个文件**：[XiaoLiuRenThreadCanvas.kt](app/src/main/java/com/example/karma/ui/divination/components/XiaoLiuRenThreadCanvas.kt)

具体改动：
1. 删除 `TrailParticle` 类 → 新增 `TrailPoint` 数据类
2. 删除 `Random` 依赖
3. 删除 `spawnParticle()`、`updateParticles()`、`drawSegmentThreads()` 三个函数
4. 新增 `drawLightDot()`、`drawTrail()` 两个 DrawScope 扩展函数
5. 重写 Canvas 绘制块：计算光点位置 → 更新缓冲区 → 绘制拖尾 → 绘制光点 → 绘制结果发光
6. 更新 `import` 语句（移除不再需要的，添加 `ArrayDeque`）
7. 同时把设计思路写入 `docs/update-v3.3/` 目录

## 验证

1. 编译通过：`./gradlew :app:compileDebugKotlin`
2. 运行 app，进入小六壬，点击"开始推算"，观察：
   - 光点从大安出发，沿路径连续移动
   - 拖尾从光点后方渐变消失（变窄+变透明）
   - 三个阶段之间有短暂停顿（光点静止，拖尾消散）
   - 最终光点停在结果宫位，脉冲发光
