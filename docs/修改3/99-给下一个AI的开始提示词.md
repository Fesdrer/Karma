# 给下一个 AI 的开始提示词

## 项目修改3：三段式事件栏 + 底部栏重构 + 占卜功能

你好！请完成 Karma 安卓应用的三项改造。所有详细步骤文档在 `docs/修改3/` 目录下。

### 需要实现的三个核心功能

1. **右侧事件栏三段化** — 将扁平的 `eventPresets` 拆分为 善业/恶业/善果 三个区段，在可滚动的容器中紧邻排列

2. **底部导航栏重构** — 从四个 Button 改为五个等宽 segment 的分段式布局，新增"占卜"入口

3. **新增占卜页面** — 纯黑背景，中央显示数字，底部"开始"按钮执行概率模拟

### 实施顺序（建议按此顺序）

### 重要提示

- 旧字段 `eventPresets` 在所有地方替换为 `goodDeedPresets`/`badDeedPresets`/`goodResultPresets`
- 善果默认预设为空列表
- EventPanel 使用 `Column` + `verticalScroll`（非 `LazyColumn`）
- Footer 使用 `Box` + `clickable` 替代 `Button`
- 占卜页面使用 `kotlin.random.Random.nextInt(1, 1001)`
- 详细实现代码见各步骤文档中的完整代码片段
