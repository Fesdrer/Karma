# 修改3：三段式事件栏 + 底部导航栏重构 + 占卜功能

## 目标

对 Karma 应用进行三项改造：

### 1. 右侧事件栏三段化

将原本扁平的事件列表拆分为三段：**善业**（上方）、**恶业**（中间）、**善果**（下方），三者紧邻排列在一个可滚动的容器中。标题不固定，随列表一起滚动。

| 善业 |
| :--- |
| 帮助他人 |
| 早起早睡 |
| 锻炼身体 |
| 恶业 |
| 发脾气 |
| 浪费粮食 |
| 口出恶言 |
| 善果 |
| （预留） |

### 2. 底部导航栏重构

从四按钮改成五等分分段式底部长条布局，去除独立 Button 组件，用 Box + 分割线实现：

```
┌──────┬──────┬──────┬──────┬──────┐
│ 确认  │ 祈福  │ 占卜  │ 历史  │ 设置  │
└──────┴──────┴──────┴──────┴──────┘
```

### 3. 新增占卜功能

纯黑背景页面，中央显示数字，底部"开始"按钮。点击后执行概率模拟并显示结果计数。

## 关键设计决策

- **数据库**：使用 Room 的 `@TypeConverters` 将 `List<String>` 存为 JSON TEXT 列；新增三列替换旧 `eventPresets` 列，数据库版本 4→5，添加 Migration
- **事件栏滚动**：使用 `Column` + `verticalScroll`（而非 `LazyColumn`），使三个区段在一个滚动容器中
- **底部栏**：使用 `Row` + `Box` + `clickable` + `Divider` 实现分段布局，每段等宽
- **占卜**：纯 Compose 页面，无数据层依赖，用 `kotlin.random.Random.nextInt` 实现
