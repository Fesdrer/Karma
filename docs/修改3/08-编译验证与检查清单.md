# 步骤 08：编译验证与检查清单

## 目标

在所有代码修改完成后，验证项目能否正确编译、运行，并逐项检查功能是否正常。

---

## 8.1 编译检查

```bash
./gradlew assembleDebug
```

若无编译错误，会在 `app/build/outputs/apk/debug/` 下生成 `Karma-v2.0.apk`（版本号可能变化）。

### 常见编译错误排查

| 错误现象 | 可能原因 | 解决 |
|---------|---------|------|
| `Unresolved reference: eventPresets` | Entity/ViewModel 中还有引用旧字段 | 全局搜索 `eventPresets`，确保全部替换 |
| `unresolved reference: goodDeedPresets` | 忘记更新 ViewModel 或 UI 中的引用 | 检查 MainViewModel、SettingsViewModel |
| `Too many arguments for public fun Footer(...)` | MainScreen 中 Footer 调用参数不匹配 | 检查参数列表是否包含 `onDivination` |
| `None of the following functions can be called with the arguments supplied` | EventPanel 参数不匹配 | 检查传入的是三个列表还是一个 |
| `Type mismatch: inferred type is List<String> but ... was expected` | 字段类型不匹配 | 检查 Entity 字段声明 |
| `Migration 4_5 not found` | 忘记添加 MIGRATION_4_5 到 addMigrations | 检查 KarmaDatabase.kt |

## 8.2 功能检查清单

### 事件栏三段化
- [ ] 事件栏显示三个区段：善业、恶业、善果
- [ ] 善业标题为绿色，恶业为红色，善果为金色
- [ ] 区段间可一同滚动（无固定标题）
- [ ] 点击善业/恶业中的事件可选中（金色高亮）
- [ ] 善果区段显示提示文字且不可选中
- [ ] 自定义事件输入框正常工作

### 底部导航栏
- [ ] 显示五个 segment：确认、祈福、占卜、历史、设置
- [ ] segment 之间有竖线分割
- [ ] 确认和祈福使用语义色（蓝/金）
- [ ] 其他 segment 使用淡色样式
- [ ] 确认按钮在无选中时禁用
- [ ] 祈福按钮在总分 < 30 时禁用
- [ ] 点击各 segment 导航到正确页面

### 占卜功能
- [ ] 占卜页面全屏黑色背景
- [ ] 初始显示 "?" 在中央
- [ ] 点击"开始"后显示计算结果数字
- [ ] 多次点击结果不同（随机性）
- [ ] 按钮文字变为"再来一次"

### 设置页面
- [ ] 事件设置区显示三个独立文本框
- [ ] 善业/恶业/善果各有一个文本框
- [ ] 三个文本框有对应的颜色主题
- [ ] 编辑后保存生效
- [ ] 返回主屏后事件栏显示正确

### 数据库迁移
- [ ] 已有数据升级后不崩溃
- [ ] 三个新列有默认值
