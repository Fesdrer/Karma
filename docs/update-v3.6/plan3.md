# v3.6 修改记录

## 1. 修复大衍筮法卦象映射错误

八卦的先天序映射表写错了——震、兑、艮、巽四个卦在爻画二进制和伏羲先天序之间的对应关系全部填反了。这导致筮法推导出的本卦和变卦都是错的。改正了 `HexagramRevelation.kt` 里的两张映射表，同时修复了 `YarrowViewModel.kt` 中变爻值的老阴→少阳、老阳→少阴的赋值错误。另外修复了运气增幅计算中"业力衰减"事件被漏判的问题（之前只跳过了善果和祈福，没跳过业力衰减）。

## 2. 颜色选择器改造：从纯 R/G/B 数字输入改为 HSV 滑块

设置页里选颜色（刻度颜色、指引线颜色、阶位颜色）之前是三个 R/G/B 数字输入框，交互不直观。之前试过引第三方颜色选择库，但 Kotlin 版本不兼容。于是用 Material3 自带的 Slider 手写了一个 HSV 取色器：色相条（0-360°彩虹渐变）、饱和度条、明度条，外加实时色块预览。后来用户要求同时保留数字输入，又在滑块下方加了一行 R/G/B 数字框，滑块拖动时数字同步变化，输入数字时滑块也同步移动，数字框允许删空不崩溃。

## 3. 历史页 JSON 导出/导入增加设置项

之前导出/导入 JSON 只包含总分和历史记录，设置页的所有配置（颜色、字体、衰减参数、阶位名称/阈值、事件预设、运气参数等）都不在备份范围内。修改后导出 JSON 时把整个 `KarmaSettingsEntity` 序列化嵌入 `"settings"` 键，导入时检测是否存在该键来区分新旧格式。CSV 格式保持不变（表格格式不适合嵌套结构）。

## 4. 全局衬线字体 + 背景"天地玄黄"渐变

把整个应用的字体从系统默认无衬线体改为思源宋体（Noto Serif SC），通过 `Type.kt` 统一配置，`Theme.kt` 的 `KarmaTheme` 中通过 `CompositionLocalProvider` 全局注入。

同时在 `Theme.kt` 中加了三层背景渐变效果：玄天（纯黑基底 #0A0A0A）、地黄（底部暗金暖色辉光）、氛围层（极淡暗金渐变覆盖）。这个三层"天地玄黄"渐变后来被简化成单层垂直渐变（见第 9 项）。

## 5. 去掉多处硬编码的黑色背景

大衍筮法页面内层 `YarrowCanvas` 之前画了纯黑不透明背景，把 Theme 的地黄暖光遮住了。去掉后让背景渐变透出来。`MainScreen` 的 `Scaffold` 容器背景也改为透明，不再遮盖主题渐变。`TimerScreen` 的硬编码深蓝黑背景同样去掉。

## 6. 调整背景色

地黄层的颜色从偏橙的 `#1A0800` 改为偏金黄的 `#1A1404`，氛围层的 alpha 从 7%/15% 调整到 8%/19%，让暗金辉光更明显。

## 7. 页面切换加渐入渐出动画

之前所有页面切换是瞬间硬切，没有过渡。在 `NavGraph.kt` 中给全部六个页面（Main、History、Prayer、Settings、Divination、Timer）都加了 `fadeIn(tween(300))` / `fadeOut(tween(300))` 的渐入渐出动画。同时在 `MainActivity.kt` 中把状态栏和导航栏颜色设为深色 `(10,10,10)`，图标浅色，匹配应用整体暗色风格。

## 8. 修复状态栏遮盖页面 + UI 组件加金色边框

多个页面（设置、历史、占卜）的顶部被系统状态栏遮住了。给各页面的根布局加了 `statusBarsPadding()` 处理。

同时给大量 UI 组件加了金色（Gold）边框：主页的 Header、ScorePanel、EventPanel、Footer，占卜页的底部按钮栏、小六壬输入面板，设置页的 SettingsCard、衰减时间选框、阶位卡片。视觉效果从之前的纯暗色面板变成了暗底金边的卡片风格。ScorePanel 的刻度区域内之前有一层深色背景矩形，也去掉了。

## 9. 氛围层移入内容之下

之前氛围渐变覆盖层画在 `content()` 之后，导致页面内容（特别是浅色文字和色块）被染上一层金黄的色偏。把氛围层移到 `content()` 之前渲染，让内容保持本色不受渐变覆盖。

## 10. 背景渐变改为可配置 + 简化为单层渐变

原来的三层"天地玄黄"渐变被我过度设计了——用户要的就只是一个"从颜色 A 渐变到颜色 B"的简单垂直渐变。所以：
- 删掉三层叠加的 Box 结构，改为单层 `Brush.verticalGradient(fromColor, toColor)`
- 在 `KarmaSettingsEntity` 中新增两个设置项：`themeGradientBaseColor`（渐变起始色，顶部）和 `themeGradientAccentColor`（渐变结束色，底部）
- 在设置页面新增"背景渐变设置"卡片，使用和阶位颜色相同的 HSV+RGB 取色器来选色
- 默认值从纯黑→亮暗金改为 `(20,25,35)` → `(60,42,5)`（深蓝灰→暗褐）
- 数据库版本从 8 升到 9，新增迁移脚本

修改保存后全局渐变立即生效，无需重启。
