# Karma v3.1 — UI 优化与历史页面增强

## 概述

本更新对 Karma App 进行四项 UI/UX 优化，重点是历史页面的导航和交互增强。

### 改动清单

| # | 改动 | 涉及文件 | 复杂度 |
|---|------|---------|--------|
| 1 | 历史页面：日期导航 + 缩放下钻 + 阶位色带 | 3 个文件 | ⭐⭐⭐ 核心 |
| 2 | EventPanel "自定义事件..." 字体调小 | 1 个文件 | ⭐ |
| 3 | 设置重置排除事件列表 | 2 个文件 | ⭐ |
| 4 | 分数面板显示当前选中值 | 2 个文件 | ⭐⭐ |

### 设计原则

- 所有 UI 风格与现有深色主题一致（暗色科技感）
- 新交互不破坏现有操作流程
- 视觉层次分明，不喧宾夺主
