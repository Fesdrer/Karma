# 修改日志 - 变更 5

**文件：** `AxisCanvas.kt`
**日期：** 2026/06/15
**修改内容：** 将非线性映射指数从 0.2314 改为 0.3654

## 修改详情

1. 修改常量 `AXIS_COMPRESSION_EXPONENT = 0.2314f` → `0.3654f`
2. 同时缩小轴上所有字体至约 0.8x：
   - 主刻度标签: 24f → 19f
   - 偶数刻度标签: 24f → 19f
   - 范围标签(顶/底): 20f → 16f
   - 当前分数标签: 26f → 21f

## 数学原理

要求：`+15` 分映射到 canvas 1/4 高度位置

解方程 `(15/100)^e = 0.5`：
- `e * ln(0.15) = ln(0.5)`
- `e = ln(0.5) / ln(0.15) ≈ 0.3654`

## 效果

- +15 在 1/4 位置（旧：+5 在 1/4）
- 近中心区域更压缩，可显示更多分数（更密集）
- 字体缩小后轴上信息更紧凑

## 验证

- `AXIS_DISPLAY_RANGE = 100f` 保持不变
- 动画、背景、段位色带、指针逻辑不变
- 刻度算法不变（idealTicks=16）
