## 任务 4：占卜每日次数限制

`data/repository/KarmaRepository.kt` 新增（沿用 `formatDate`、`getRank`）：
```kotlin
fun getDivinationLimit(settings: KarmaSettingsEntity): Int {
    val level = getRank(settings.totalScore, settings)?.level ?: 1  // 负阶 level<0 → 走 low
    return if (level <= settings.divinationLimitBoundary) settings.divinationLimitLow else settings.divinationLimitHigh
}
fun getDivinationRemaining(settings: KarmaSettingsEntity): Int {
    val today = formatDate(System.currentTimeMillis())
    val count = if (settings.divinationDate == today) settings.divinationCount else 0
    return (getDivinationLimit(settings) - count).coerceAtLeast(0)
}
suspend fun recordDivination() { /* 日期=今天 → count+1，否则 count=1，upsert */ }
```

## 任务 6：负数阶位

`data/repository/KarmaRepository.kt` 改 `getRank`（L341-345）：
```kotlin
fun getRank(score: Float, settings: KarmaSettingsEntity): Rank? {
    if (score < 0f) {
        // 负阶：(-10,0]→-1，(-20,-10]→-2，…，(-∞,-80]→-9；ts 为降序 [-10,-20,…,-80]
        val ts = settings.negativeRankThresholds
        val names = settings.negativeRankNames
        val level = if (ts.isEmpty()) 1 else when {
            score > ts[0] -> 1
            ts.size > 1 && score > ts[1] -> 2
            ts.size > 2 && score > ts[2] -> 3
            ... ts.size > 7 && score > ts[7] -> 8
            else -> 9
        }
        return Rank(
            min = if (level == 9) -Float.MAX_VALUE else ts.getOrElse(level - 1) { -80f },
            max = if (level == 1) 0f else ts.getOrElse(level - 2) { -10f },
            level = -level,
            name = names.getOrElse(level - 1) { "?" },
            colorHex = 0xFF8b0000,   // 负阶统一暗红（每级异色暂不扩展）
        )
    }
    // 正阶逻辑不变（score==0 归壹阶）
}
```
- `Header.kt` L114-121：`else if (totalScore < 0)` 显示「—」的分支变为死代码 → 删除（负阶现在走 rank!=null 分支，徽章显示名称，白字 + 暗红底，现有逻辑自动适配：`rank.level <= totalRanks*2/3` 对负 level 恒真 → 白字 ✓）
- `MainViewModel` L112、`PrayerViewModel` L37-42、`DivinationScreen` L108-110 的 `rank?.level ?: 1` 无需改：负阶 level<0 → 占卜 3 阶锁定 ✓、占卜次数走 low 档 ✓（PrayerScreen 若显示 rankLevel 数字，实现时核对显示文案，必要时显示名称）
- `getDecayRank`（L314-328）不动：任务 5 守卫后负分不再到达

设置页 RankSettingsCard（L991 起）内新增「负数阶位」节，模式照抄现有正阶编辑：
- 9 个名称输入（模式同 `updateRankNames` 多行文本框，SettingsViewModel L189-197）
- 8 个阈值 ± 步进（模式同 `updateRankThreshold` L173-179；负数阈值允许负值，无 0 限制）

## 任务 3：键盘有时不弹出（阶段二单独做）

第一假设（可验证）：Manifest 未设置 `windowSoftInputMode`（默认 adjustUnspecified），配合 `enableEdgeToEdge()`（decorFitsSystemWindows=false）在部分设备/系统版本上导致 IME 不弹出或弹出即收回。

`AndroidManifest.xml` activity 加：`android:windowSoftInputMode="adjustResize"`（Compose + edge-to-edge 官方推荐配置）。

排查确认：DivinationScreen/XiaoLiuRenContent 无全屏 clickable/pointerInput 层盖住输入框（已核实各 Box 均无 clickable）。

若装机后仍复现：第二假设为输入框处于页面切换动画期 → 给输入框加 FocusRequester，进入输入状态时主动 requestFocus（此假设暂不改，等复现再说）。
