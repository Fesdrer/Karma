# 业力值模拟器 — Android 重构计划

> 最后更新: 2026-06-14
> 此文件为计划方案副本，实施过程中如有调整会同步更新

## Context

将 HTML 版「业力值模拟器」完整重构为原生 Android 应用。当前项目是一个空壳 Compose 应用（只有一句「你好」），而 HTML 包含完整的业力值追踪系统：三栏仪表盘、Canvas 可视化轴、交互式折线图、粒子动画祈福效果、预设编辑器、9 阶段位系统、CSV/JSON 导入导出。

本次重构将其翻译为 Kotlin + Jetpack Compose + Room 的原生实现，保留所有功能和视觉效果，同时遵循 Android 平台最佳实践。

---

## 架构

- **MVVM + Repository** — ViewModel 管理 UI 状态，Repository 封装数据操作
- **Room** 替代 `localStorage` — `history_entries` 表和 `karma_settings` 单行表
- **Navigation Compose** — 三个目的地：Main / History / Prayer
- **手动 DI** (`AppContainer`) — 应用规模适度，避免 Hilt 的注解处理开销
- **Compose Canvas** 替代 HTML Canvas — 轴、图表、粒子引擎全部用 `Canvas` composable
