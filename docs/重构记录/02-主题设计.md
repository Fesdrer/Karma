# 步骤2: 主题设计

## 目标
将 Material3 默认的 Purple 主题替换为 Karma 应用的暗色主题色板。

## 涉及文件
- `Color.kt` — 完整替换为 Karma 暗色色板
- `Theme.kt` — 锁定暗色，移除动态颜色和亮色模式
- `Type.kt` — 增加多级文字样式定义

## 决策记录

### 色板设计
| 用途 | HTML 颜色 | Android 颜色 | 说明 |
|------|-----------|-------------|------|
| 背景 | #1a1a2e | DarkNavy | 主背景色 |
| 面板 | #16213e | PanelBg | 卡片/面板背景 |
| 强调 | #0f3460 | AccentBg | 按钮/容器强调色 |
| 金色 | #ffd700 | Gold | 分数、段位、装饰 |
| 蓝色 | #a0c4ff | BlueLight | 按钮文字 |
| 蓝色按钮 | #4a90d9 | BluePrimary | 确认按钮 |
| 红色 | #ff5252 | RedNegative | 负值、错误 |
| 绿色 | #69f0ae | GreenPositive | 正值 |

### 主题设计
- 移除了 `dynamicColor` 参数，锁定为单色调色板
- 移除了亮色模式 `lightColorScheme` 分支
- KarmaTheme 不再接受 `darkTheme` 和 `dynamicColor` 参数

### 字体
- 使用 `FontFamily.Default`（Android 系统字体已完整支持 CJK）
- 增加了多级文字样式 (displayLarge/Medium, titleLarge/Medium, etc.) 以适应不同 UI 元素
