# 步骤1: 项目配置

## 目标
更新 Gradle 版本目录和模块级构建文件，添加 Room、Navigation Compose、Lifecycle ViewModel Compose、Gson 等新依赖，以及 KSP 插件。

## 涉及文件
- `gradle/libs.versions.toml` — 新增版本号、库、插件条目
- `app/build.gradle.kts` — 新增 KSP 插件和依赖项

## 决策记录

### 版本选择
| 依赖 | 版本 | 选择理由 |
|------|------|----------|
| Room | 2.6.1 | 与 compileSdk 34 兼容的稳定版本 |
| KSP | 1.9.0-1.0.13 | 匹配 Kotlin 1.9.0 |
| Navigation Compose | 2.7.7 | 与 Compose BOM 2024.04 兼容 |
| Lifecycle ViewModel Compose | 2.6.1 | 与现有 lifecycle-runtime-ktx 一致 |
| Gson | 2.10.1 | 轻量级 JSON 序列化，用于 Room TypeConverters |

### 注意事项
- KSP 版本必须与 Kotlin 版本精确匹配（1.9.0-1.0.13）
- Room 的 ksp 配置使用 `ksp()` 而非 `annotationProcessor()`
- 现有 Compose BOM 2024.04.01 涵盖 Compose UI 1.6.x，与 Navigation Compose 2.7.x 兼容
