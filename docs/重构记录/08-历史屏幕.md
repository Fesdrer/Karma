## HistoryViewModel.kt

### 状态流

```kotlin
val uiState = repository.allHistory.map { entries ->
    HistoryUiState(
        entries = entries,
        viewMode = _viewMode.value,
        aggregatedPoints = aggregate(entries, mode),
        message = _message.value,
    )
}.stateIn(viewModelScope, WhileSubscribed(5000), HistoryUiState())
```

- 使用 `map` + `stateIn` 而非 `combine`，保证每次数据变更自动重新聚合
- `WhilesSubscribed(5000)` 在配置变更时保持 5s 窗口避免重启

### 数据聚合

| ViewMode | 分组键 | 每组取 |
|----------|--------|--------|
| `DAY` | 无分组 | 所有记录逐条显示 |
| `WEEK` | `"yyyy-Www"` | 最后一条（最新） |
| `MONTH` | `"yyyy-MM"` | 最后一条（最新） |

```kotlin
private fun aggregate(entries, mode): List<AggregatedPoint> {
    if (mode == DAY) return entries.map { it.toAggregated() }
    // 按周/月分组，保留每组最后一条
    val groups = mutableMapOf<String, HistoryEntryEntity>()
    for (entry in entries) {
        val key = when (mode) {
            WEEK  → "$year-W${cal.get(WEEK_OF_YEAR).padStart(2,'0')}"
            MONTH → "$year-${cal.get(MONTH)+1}.padStart(2,'0')"
        }
        groups[key] = entry  // 数据已排序，后覆盖前即保留最新
    }
    return groups.sortedByKey().map { it.toAggregated() }
}
```

### 导出业务

| 方法 | 格式 | BOM | 备注 |
|------|------|-----|------|
| `exportCsv(uri)` | timestamp,delta,event,totalAfter,type | 是 (0xFEFF) | 通过 `repository.exportCsv()` |
| `exportJson(uri)` | 嵌套 JSON 对象 | 否 | 通过 `repository.exportJson()` |

### 导入业务

- 通过 `uri.lastPathSegment` 判断格式（.json 结尾为 JSON，否则为 CSV）
- 调用 `repository.importData(text, format)` 执行解析和写入
- 导入成功/失败通过 `_message` 反馈

## HistoryChartCanvas.kt

### ChartViewport（同一文件内定义）

```kotlin
data class ChartViewport(
    var viewStart: Double = 0.0,   // 可视范围起始时间戳
    var viewEnd: Double = 0.0,     // 可视范围结束时间戳
    var yMin: Float = 0f,          // Y 轴最小值
    var yMax: Float = 10f,         // Y 轴最大值
)
```
- 使用 `var` 而非 `val`，允许 Canvas 首次绘制时自动适配范围
- 支持后续通过手势平移/缩放操作修改

### 自动适配逻辑

```kotlin
if (vp.viewEnd <= vp.viewStart) {
    // X 轴：时间范围 ±10% 内边距
    val timeRange = points.last().timestamp - points.first().timestamp
    vp.viewStart = first.timestamp - timeRange * 0.1
    vp.viewEnd = last.timestamp + timeRange * 0.1
    // Y 轴：数值范围 ±15% 内边距，最小 5f
    vp.yMin = min(score) - yPad
    vp.yMax = max(score) + yPad  // 最小跨度 10f
}
```

### 坐标映射

```kotlin
val xMap: (Long) -> Float = { t →
    PAD_LEFT + ((t - viewStart) / (viewEnd - viewStart) * plotW).toFloat()
}
val yMap: (Float) -> Float = { s →
    PAD_TOP + (1f - (s - yMin) / (yMax - yMin)) * plotH
}
```

### 绘制顺序（6 层）

1. **背景** — `ChartBg` (`#0d1b2a`)
2. **网格线** — 5 条水平线（alpha 0.06），右侧显示对应分数标签
3. **时间标签** — 5 等分 X 轴，`MM/dd` 格式（`nativeCanvas.drawText`）
4. **折线** — `Path.moveTo` + `lineTo` 连接所有数据点，金色 2px stroke
5. **数据点圆** — 最多 200 个点，step 均匀采样，金色填充 + 背景色描边
6. **面积填充** — 折线到 X 轴的闭合区域，金色 alpha 0.08

### 常量

| 常量 | 值 | 用途 |
|------|-----|------|
| `PAD_TOP` | `20f` | 上内边距 |
| `PAD_RIGHT` | `20f` | 右内边距 |
| `PAD_BOTTOM` | `40f` | 下内边距（为时间标签留空） |
| `PAD_LEFT` | `60f` | 左内边距（为分数标签留空） |

## 与 HTML 原版的差异

- **HTML 使用 Chart.js 库**，Compose 完全自绘 Canvas 折线图
- **HTML 缩放通过鼠标滚轮**，Compose 需 `detectTransformGestures`（待实现）
- **HTML 的 tooltip 随鼠标位置实时更新**，当前为占位实现
- **数据聚合**：HTML 可能使用后端聚合，Compose 使用 `Calendar` 本地计算
- **文件导入导出**：HTML 使用浏览器 File API，Compose 使用 Android SAF（`ActivityResultContracts`）
- **CSV 编码**：Android 使用 BOM (`0xFEFF`) 确保 Excel 正确识别 UTF-8 中文
