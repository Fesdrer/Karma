## MainScreen.kt

**布局结构**（与 HTML 三栏 `flex` 对应）：

```
Column {
    Header                ← Row: score + rank badge
    Spacer(12.dp)
    Row(weight=1f) {      ← 三栏 body
        ScorePanel(weight=1f)     ← 左 1/3
        Spacer(6.dp)
        AxisCanvas(width=75.dp)   ← 中央轴，固定宽度
        Spacer(6.dp)
        EventPanel(weight=1f)     ← 右 1/3
    }
    Footer                ← 三个按钮
}
```

- `modifier` 参数支持外部传入，便于 NavHost 组合
- 通过 `viewModel(factory = ...)` 创建 `MainViewModel`，依赖 `AppContainer.repository`
- 编辑弹窗（ScoreEditModal、EventEditModal）通过状态 `scoreEditMode` / `eventEditMode` 条件渲染，不依赖 Navigation

## MainViewModel.kt

### combine 链架构

使用三层嵌套 combine 解决 Kotlin 类型推断限制（单次 combine 最多约 5 参数会失败）：

```kotlin
第1层：_selectedScore + _customScore       → _effectiveScore
      _selectedEvent + _customEvent         → _effectiveEvent
第2层：_effectiveScore + _effectiveEvent     → _selectedPair
      _scoreEditMode + _eventEditMode        → _editModePair
第3层：repository.settings + _selectedPair + _editModePair → uiState
```

### StateFlow 定义

| StateFlow | 类型 | 用途 |
|-----------|------|------|
| `_selectedScore` | `MutableStateFlow<Float?>` | 预设分数选择 |
| `_selectedEvent` | `MutableStateFlow<String?>` | 预设事件选择 |
| `_customScore` | `MutableStateFlow<Float?>` | 自定义分数输入 |
| `_customEvent` | `MutableStateFlow<String?>` | 自定义事件输入 |
| `_scoreEditMode` | `MutableStateFlow<Boolean>` | 分数编辑弹窗开关 |
| `_eventEditMode` | `MutableStateFlow<Boolean>` | 事件编辑弹窗开关 |

### 用户操作映射

| 操作 | 方法 | 效果 |
|------|------|------|
| 点击分数预设 | `selectScore(v)` | `_selectedScore = v; _customScore = null` |
| 点击事件预设 | `selectEvent(v)` | `_selectedEvent = v; _customEvent = null` |
| 输入自定义分数 | `onCustomScoreChanged(t)` | 解析 Float，更新 `_customScore` |
| 输入自定义事件 | `onCustomEventChanged(t)` | 非空时更新 `_customEvent` |
| 确认 | `onConfirm()` | 调用 `repository.addHistoryEntry(delta, event)` |
| 编辑分数 | `openScoreEdit()` / `closeScoreEdit()` | 切换弹窗状态 |
| 编辑事件 | `openEventEdit()` / `closeEventEdit()` | 切换弹窗状态 |
| 保存预设 | `saveScorePresets(list)` / `saveEventPresets(list)` | 写入 Room + 关闭弹窗 |

## AxisCanvas.kt

### 核心映射函数 `scoreToY`

与 HTML 版精确一致的 `pow(absD, 0.6)` 非线性映射：

```kotlin
private fun scoreToY(score, centerScore, halfH, canvasH): Float {
    val d = score - centerScore
    val sign = sign(d)
    val absD = minOf(abs(d), AXIS_DISPLAY_RANGE * 2f)
    val scale = halfH / (AXIS_DISPLAY_RANGE.toDouble().pow(0.6)).toFloat()
    val pixelOffset = sign * (absD.toDouble().pow(0.6)).toFloat() * scale
    return canvasH / 2f - pixelOffset
}
```

### 动画

- `animateFloatAsState` + `tween(400ms)` + `FastOutSlowInEasing`
- 每次 `totalScore` 变化时，指针和目标标签平滑过渡

### 绘制顺序（7 层）

1. **背景** — `#0d1b2a` 深色 chart 背景
2. **负值区域** — `#2d2d2d` 灰色区域标识负分区间
3. **段位色带** — 遍历 `Rank.RANKS`，在当前可视范围内绘制对应颜色矩形条
4. **刻度线** — nice numbers [1, 2, 5, 10, 20, 50] 自动选择步长，主/副刻度线
5. **竖轴** — 白色半透明居中竖线
6. **指针** — 金色虚线指引线 + 右侧三角箭头 + 分数标签（`nativeCanvas.drawText`）
7. **范围标签** — 顶部/底部显示当前可视范围的最大/最小值

### 常量

| 常量 | 值 | 用途 |
|------|-----|------|
| `AXIS_DISPLAY_RANGE` | `100f` | 可视范围半径（中心分 ±100） |
| `ANIM_DURATION` | `400` | 动画时长 ms |
| `NEG_BG` | `#2d2d2d` | 负值区域背景 |
| `CHART_BG` | `#0d1b2a` | 图表背景 |

## 与 HTML 原版的差异

- **HTML 使用 `onclick` 直接操作 DOM**，Compose 使用 `StateFlow` + `ViewModel` 模式
- **CSS `flex: 1`** 映射为 Compose `Modifier.weight(1f)`
- **Canvas 绘制** 全部替换为 Compose `Canvas` composable + `DrawScope`
- **HTML 的 `easeInOutCubic`** 映射为 `FastOutSlowInEasing`
- **字体**：HTML 使用 Web 字体，Compose 使用 `nativeCanvas.drawText` + `android.graphics.Paint`
- **按钮交互**：HTML `:hover` 伪类，Compose 使用 `Material3.Button` 原生状态管理
