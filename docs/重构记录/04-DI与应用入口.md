# 步骤4: DI 与应用入口

## 目标
搭建手动依赖注入容器和应用入口。

## 涉及文件
- `di/AppContainer.kt` — 持有 Database 和 Repository
- `KarmaApplication.kt` — Application 子类，onCreate 初始化容器
- `AndroidManifest.xml` — 添加 android:name 指向 KarmaApplication
- `strings.xml` — app_name → "业力值模拟器"

## 决策记录
- **手动 DI**：不引入 Hilt/Dagger，使用简单的容器模式
- **AppContainer**：在构造时创建 Database 实例，然后从中获取 DAO，最后构建 Repository
- ViewModel 将通过 `ViewModelProvider.Factory` 或直接从 Activity 的 `Application` 获取容器实例
