## 4.2 HistoryViewModel 重写 aggregate()

**文件**: `app/src/main/java/com/example/karma/ui/history/HistoryViewModel.kt`

### 改动

1. `aggregate()` 方法从"分组取最后一条"改为"时间范围过滤"

```kotlin
private fun aggregate(
    entries: List<HistoryEntryEntity>,
    mode: ViewMode,
): List<AggregatedPoint> {
    if (entries.isEmpty()) return emptyList()
    val now = System.currentTimeMillis()
    val cal = Calendar.getInstance()

    return when (mode) {
        ViewMode.DAY -> {
            // 今天 00:00 至今的所有记录
            cal.timeInMillis = now
            cal.set(Calendar.HOUR_OF_DAY, 0)
            cal.set(Calendar.MINUTE, 0)
            cal.set(Calendar.SECOND, 0)
            cal.set(Calendar.MILLISECOND, 0)
            val todayStart = cal.timeInMillis
            entries
                .filter { it.timestamp >= todayStart }
                .map { it.toAggregated() }
        }
        ViewMode.WEEK -> {
            // 最近 7 天的所有记录
            val weekAgo = now - 7L * 24 * 60 * 60 * 1000
            entries
                .filter { it.timestamp >= weekAgo }
                .map { it.toAggregated() }
        }
        ViewMode.MONTH -> {
            // 最近 30 天的所有记录
            val monthAgo = now - 30L * 24 * 60 * 60 * 1000
            entries
                .filter { it.timestamp >= monthAgo }
                .map { it.toAggregated() }
        }
        ViewMode.ALL -> {
            // 全部记录
            entries.map { it.toAggregated() }
        }
    }
}
```

### 注意

移除了旧的按 `groups` 分组的逻辑。导入可以清理：`Calendar` 仍需使用，不再需要 `String` 格式化 key。

## 4.3 HistoryScreen 新增"全部"按钮

**文件**: `app/src/main/java/com/example/karma/ui/history/HistoryScreen.kt`

### 改动

在 ViewMode 按钮 Row 中增加第四个"全部"按钮：

```kotlin
// 原代码
ViewMode.entries.forEach { mode -> ... }

// 新代码 — 无变化，因为 ViewMode.entries 现在包含 ALL
// 但由于 ALL 的描述文字未定义，需要修改 label 生成逻辑
```

完整代码块：

```kotlin
Row(
    horizontalArrangement = Arrangement.spacedBy(4.dp),
    verticalAlignment = Alignment.CenterVertically,
) {
    ViewMode.entries.forEach { mode ->
        val isActive = state.viewMode == mode
        val label = when (mode) {
            ViewMode.DAY -> "日"
            ViewMode.WEEK -> "周"
            ViewMode.MONTH -> "月"
            ViewMode.ALL -> "全部"       // ← 新增
        }
        Box(
            modifier = Modifier
                .clip(RoundedCornerShape(8.dp))
                .then(
                    if (isActive) Modifier.background(Color(0xFF4a90d9))
                    else Modifier.background(Color(0xFF1a1a3e))
                )
                .border(
                    1.dp,
                    if (isActive) Color(0xFF4a90d9) else Color(0xFF334444),
                    RoundedCornerShape(8.dp)
                )
                .clickable { viewModel.setViewMode(mode) }
                .padding(horizontal = 10.dp, vertical = 5.dp),
        ) {
            Text(
                label,
                fontSize = 13.sp,
                fontWeight = FontWeight.SemiBold,
                color = if (isActive) Color.White else Color(0xFFa0c4ff),
            )
        }
    }
}
```

由于 `ViewMode.ALL` 新增后 `entries` 包含 4 个值，按钮总宽度会略微增加。如果你的布局足够容纳（确认过 442dp 可用宽度），不需要额外调整。若溢出，考虑缩小 `padding(horizontal = 8.dp)`。

### HistoryScreen 传递参数

在 `HistoryScreen.kt` 的调用处：

```kotlin
HistoryChartCanvas(
    points = state.aggregatedPoints,
    viewport = viewport,
    onPointClicked = { point, screenX, screenY ->
        // ... 现有逻辑 ...
    },
    // ★ 目前使用默认值（等待设置页配置）
    // 后续可从 SettingsViewModel 或另开渠道传入
    // 当前阶段使用默认值 2f / 3.5f
    modifier = Modifier.fillMaxSize(),
)
```

**注意**: 历史页的设置值暂不从 settings 读取，因为 HistoryViewModel 当前不持有 repository.settings。有两种方案：

**方案 A（简易）**: 直接硬编码默认值，等后续通过 HistoryViewModel 接入 settings
**方案 B（完整）**: 在 HistoryViewModel 中添加 `Flow<KarmaSettingsEntity>` 的 combine

推荐方案 A 先让 UI 参数化就绪，后续扩展不破坏接口。
