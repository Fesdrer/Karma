# 任务6：启动时显示经文/境界语加载画面

## 问题

应用打开后先加载黑色背景和星空，然后直接进入主界面。要求在黑色背景+星空之后、主界面出现之前，显示一段经文/境界语（金色竖排文字，从右到左），停留可配置的秒数，然后继续加载主界面。

## 修改文件

1. `app/src/main/java/com/example/karma/ui/main/MainScreen.kt` — 添加经文画面阶段
2. `app/src/main/java/com/example/karma/data/local/entity/KarmaSettingsEntity.kt` — 新增经文和时长字段
3. `app/src/main/java/com/example/karma/ui/settings/SettingsScreen.kt` — 设置页添加经文卡片
4. `app/src/main/java/com/example/karma/ui/settings/SettingsViewModel.kt` — 新增更新方法

## 不需要改的文件

- `KarmaRepository.kt` 的 `exportJson()` / `importJson()` — Gson 序列化会自动包含新字段

### Step 2: MainScreen 添加经文加载阶段

当前 MainScreen 的加载流程（约58-64行）：
```kotlin
Crossfade(targetState = state != null, animationSpec = tween(300)) { ready ->
    if (!ready) {
        Box(modifier = Modifier.fillMaxSize().background(Color.Black))
        return@Crossfade
    }
    val s = state!!
    // ... 主界面内容
}
```

修改为三段式流程：

```kotlin
enum class SplashPhase { BLACK, SCRIPTURE, MAIN }

var splashPhase by remember { mutableStateOf(SplashPhase.BLACK) }
val settings by appContainer.repository.settings.collectAsState()

// 阶段1 → 阶段2：纯黑 → 经文（在 KarmaTheme 的星空背景下显示）
LaunchedEffect(Unit) {
    // 等待首帧渲染完成，确保星空图片已显示
    // 然后从 BLACK → SCRIPTURE
    splashPhase = SplashPhase.SCRIPTURE
}

// 阶段2 → 阶段3：经文停留 splashDurationSec 秒后 → 主界面
val scriptureText = settings.splashScripture
val durationMs = (settings.splashDurationSec * 1000L).coerceAtLeast(1000L)
LaunchedEffect(splashPhase) {
    if (splashPhase == SplashPhase.SCRIPTURE) {
        delay(durationMs)
        splashPhase = SplashPhase.MAIN
    }
}
```

然后在渲染部分：

```kotlin
when (splashPhase) {
    SplashPhase.BLACK -> {
        Box(modifier = Modifier.fillMaxSize().background(Color.Black))
    }
    SplashPhase.SCRIPTURE -> {
        // 经文画面 — 背景已经由 KarmaTheme 的 gradient + 星星图片提供
        // 这里只需要绘制金色竖排文字覆盖层
        ScriptureOverlay(
            text = scriptureText,
            modifier = Modifier.fillMaxSize(),
        )
    }
    SplashPhase.MAIN -> {
        // 原有的 Crossfade(state != null) 逻辑
        Crossfade(...) {
            if (!ready) Box(fillMaxSize, background(Color.Black))
            else { /* 主界面 */ }
        }
    }
}
```

**注意**：经文画面必须能够"穿透"看到底层的星星背景。KarmaTheme 中星星图片在 `content()` 之上渲染（Theme.kt:68-80），所以经文画面需要在同一层级。

**实现位置关键**：经文画面的渲染应该在 `KarmaTheme` 的 `content` lambda 内部，即 MainScreen 本身。因为 `KarmaTheme` 已经提供了：
```
Box(渐变背景) {
    content()           ← MainScreen 渲染在这里
    Box(星星图片)       ← 在 content 之上
}
```

所以经文覆盖层需要在 MainScreen 中渲染，利用星星图片已在底层的特性。

**经文竖排渲染**：使用 `ScriptureOverlay` 组件，用 Canvas 绘制每个字符：

```kotlin
@Composable
fun ScriptureOverlay(text: String, modifier: Modifier = Modifier) {
    Canvas(modifier = modifier.fillMaxSize()) {
        val w = size.width
        val h = size.height
        
        // 计算自适应字体大小
        val charCount = text.length
        // 竖排：每列1个字，从右到左排列
        // 列数 = charCount，列间距 = fontSize * 0.5
        // 可用宽度 / (fontSize + 列间距) >= charCount
        // 可用高度 >= fontSize * 1.4
        
        val maxFontSizeByWidth = w.toFloat() / (charCount * 1.5f)  // 每个字占 1.5倍字号宽度（含间距）
        val maxFontSizeByHeight = h.toFloat() / 1.4f               // 单行高度
        val fontSize = min(maxFontSizeByWidth, maxFontSizeByHeight)
        
        val paint = android.graphics.Paint().apply {
            color = android.graphics.Color.argb(255, 255, 215, 0)  // 金色
            textSize = fontSize
            isAntiAlias = true
            typeface = android.graphics.Typeface.SERIF  // 衬线体
            textAlign = android.graphics.Paint.Align.CENTER
        }
        
        val charHeight = fontSize * 1.3f
        val charWidth = fontSize
        val columnSpacing = charWidth * 0.5f
        
        // 从右到左绘制每个字符
        // 最右边一列为第0个字符
        val startX = w - (charWidth / 2f)  // 第一列（最右列）中心X
        val centerY = h / 2f  // 垂直居中
        
        text.forEachIndexed { index, ch ->
            val colX = startX - index * (charWidth + columnSpacing)
            val charY = centerY + charHeight / 2f  // drawText 的 y 是基线
            
            drawContext.canvas.nativeCanvas.drawText(
                ch.toString(),
                colX,
                charY,
                paint
            )
        }
    }
}
```

### Step 3: SettingsScreen 添加经文设置卡片

在设置页的卡片列表（约156-250行）中，在 `LuckSettingsCard` 之后、`BackgroundGradientCard` 之前（或最后 `ResetCard` 之前）添加：

定义 `SplashSettingsCard` composable：

```kotlin
@Composable
private fun SplashSettingsCard(
    splashScripture: String,
    splashDurationSec: Int,
    onScriptureChange: (String) -> Unit,
    onDurationChange: (Int) -> Unit,
) {
    SettingsCard("启动经文") {
        Text(
            "输入启动时显示的经文或境界语（金色竖排文字，自动缩放）",
            fontSize = 12.sp,
            color = TextSecondary,
        )
        Spacer(Modifier.height(12.dp))
        
        // 经文文本输入
        Text("经文内容", style = MaterialTheme.typography.bodyMedium, color = TextSecondary)
        Spacer(Modifier.height(4.dp))
        OutlinedTextField(
            value = splashScripture,
            onValueChange = onScriptureChange,
            modifier = Modifier.fillMaxWidth().heightIn(min = 80.dp),
            singleLine = false,
            minLines = 3,
            textStyle = MaterialTheme.typography.bodySmall.copy(
                fontFamily = FontFamily.Serif,
                color = Color(0xFFffd700),  // 金色文字
            ),
            colors = OutlinedTextFieldDefaults.colors(
                focusedBorderColor = Gold,
                unfocusedBorderColor = BorderSubtle,
                focusedTextColor = Color(0xFFffd700),
                unfocusedTextColor = Color(0xFFffd700),
                cursorColor = Gold,
            ),
        )
        
        Spacer(Modifier.height(16.dp))
        
        // 停留秒数
        Text("停留秒数", style = MaterialTheme.typography.bodyMedium, color = TextSecondary)
        Spacer(Modifier.height(4.dp))
        var durationText by remember(splashDurationSec) { mutableStateOf(splashDurationSec.toString()) }
        OutlinedTextField(
            value = durationText,
            onValueChange = { v ->
                durationText = v
                v.toIntOrNull()?.let { onDurationChange(it.coerceIn(1, 30)) }
            },
            modifier = Modifier.widthIn(min = 70.dp),
            singleLine = true,
            textStyle = MaterialTheme.typography.bodyMedium.copy(fontFamily = FontFamily.Serif),
            keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Number),
            colors = OutlinedTextFieldDefaults.colors(
                focusedBorderColor = Gold,
                unfocusedBorderColor = BorderSubtle,
                focusedTextColor = TextPrimary,
                unfocusedTextColor = TextPrimary,
            ),
        )
        Spacer(Modifier.height(4.dp))
        Text("建议 1~10 秒", fontSize = 11.sp, color = TextMuted)
    }
}
```
