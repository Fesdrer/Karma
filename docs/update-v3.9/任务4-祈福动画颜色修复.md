# 任务4：祈福动画文字颜色修复

## 问题

动画上显示的祈福事情（purpose）有时是黑色，应当是纯红色。

## 原因

`ParticleEngineCanvas.kt` 中创建了两个 `TextPaint` 用于绘制 StaticLayout 中的祈福目的文本：

```kotlin
// 第148-150行：divineTextPaint — 最高阶位（神阶）
val divineTextPaint = remember {
    android.text.TextPaint().apply { isFakeBoldText = true; isAntiAlias = true }
}

// 第154-156行：normalTextPaint — 普通阶位
val normalTextPaint = remember {
    android.text.TextPaint().apply { isAntiAlias = true }
}
```

**这两个 TextPaint 没有设置 color 属性**。`android.text.TextPaint` 的默认颜色是 `Color.BLACK`（`0xFF000000`），在深色背景上文字呈现为黑色，肉眼不可见/看起来像是缺失。

相比之下，其他 paint 都显式设置了颜色：
- `amountPaint`（第143-147行）— 每帧设置 `color = android.graphics.Color.argb(textAlpha, 255, 34, 34)`（第338行）
- `divineBracketPaint`（第151-153行）— 每帧设置 `color = android.graphics.Color.argb(textAlpha, 255, 34, 34)`（第309行）
- `normalBracketPaint`（第157-159行）— 每帧设置 `color = android.graphics.Color.argb(textAlpha, 255, 0, 0)`（第349行）

## 修改方案

### 修改文件

`app/src/main/java/com/example/karma/ui/prayer/ParticleEngineCanvas.kt`

### 修改点1：为 TextPaint 设置基础颜色

在 `divineTextPaint` 和 `normalTextPaint` 的创建块中设置颜色为纯红：

```kotlin
// 第148-150行，改为：
val divineTextPaint = remember {
    android.text.TextPaint().apply {
        isFakeBoldText = true
        isAntiAlias = true
        color = android.graphics.Color.RED  // 或 0xFFFF0000.toInt()
    }
}

// 第154-156行，改为：
val normalTextPaint = remember {
    android.text.TextPaint().apply {
        isAntiAlias = true
        color = android.graphics.Color.RED  // 或 0xFFFF0000.toInt()
    }
}
```

### 修改点2：在 StaticLayout 绘制前动态更新透明度

`divineTextPaint` 和 `normalTextPaint` 的 `alpha` 需要在每帧绘制时动态设置，以匹配 `textFade` 的渐入渐出效果。

在绘制代码中，`cachedLayout.draw()` 之前，设置 paint alpha：

```kotlin
// 第319行附近（divine分支）：
divineTextPaint.alpha = textAlpha  // ← 新增
cachedLayout.draw(drawContext.canvas.nativeCanvas)

// 第359行附近（normal分支）：
normalTextPaint.alpha = textAlpha  // ← 新增
cachedLayout.draw(drawContext.canvas.nativeCanvas)
```

由于 `StaticLayout` 使用的是构建时传入的 paint 副本，`divineTextPaint.alpha` 的修改**不会**影响已构建的 `StaticLayout` 中的文字颜色。需要改用 `divineTextPaint.alpha` 并重新构建 layout，或者在 `layout.draw(canvas)` 调用前确保 layout 内部使用的是正确的 paint。

更可靠的做法是：**在 `ensureLayouts` 中设置 color 时带上 alpha**，因为 `StaticLayout.Builder.obtain()` 接受的是 `TextPaint` 引用——但验证显示 `TextPaint` 的 mutation 是生效的。

实际上 `TextPaint` 是可变对象，`StaticLayout.Builder.obtain()` 内部复制了 paint 状态。所以改为在每次绘制时重新构建 layout 且传入带 alpha 的 paint 效率太差。

**正确做法**：由 `divineTextPaint` / `normalTextPaint` 携带最终颜色（带 alpha），在 `ensureLayouts` 时设置完整颜色。因为 layout 只有 canvasW 或 purpose 变化时才重建，但是 alpha 每帧都在变。折中方案：将 alpha 控制移到 `ensureLayouts` 中的 paint 设置，并在每帧调用 `ensureLayouts` 时传入 textAlpha。

**最简修复方案**：
1. 在 `ensureLayouts` 中添加 `alpha: Int` 参数
2. 在构建 StaticLayout 之前设置 `divineTextPaint.alpha = alpha` / `normalTextPaint.alpha = alpha`
3. 在调用 `ensureLayouts` 时传入当前 `textAlpha`

修改 `ensureLayouts` 签名：
```kotlin
fun ensureLayouts(
    canvasW: Float,
    purpose: String,
    divineTextPaint: android.text.TextPaint,
    normalTextPaint: android.text.TextPaint,
    scale: Float,
    textAlpha: Int = 255,  // ← 新增
)
```

在函数内：
```kotlin
divineTextPaint.alpha = textAlpha  // ← 构建前设置alpha
cachedDivineLayout = android.text.StaticLayout.Builder
    .obtain(purpose, 0, purpose.length, divineTextPaint, maxWidth)
    // ...
```

调用处（第295行）改为：
```kotlin
state.ensureLayouts(w, purpose, divineTextPaint, normalTextPaint, scale, textAlpha)
```

这样每次 `textAlpha` 变化时，`ensureLayouts` 中新 alpha 与缓存 key 不匹配 → 重建 StaticLayout。但由于 `lastLayoutCanvasW` 和 `lastLayoutPurpose` 没变而 alpha 变了，需要**将 alpha 加入缓存 key**。

**更简洁的方案**：将 `textAlpha` 加入缓存 Key，修改 `ensureLayouts` 缓存的判断条件：

```kotlin
private var lastLayoutCanvasW: Float = -1f
private var lastLayoutPurpose: String = ""
private var lastLayoutAlpha: Int = -1  // ← 新增

fun ensureLayouts(canvasW: Float, purpose: String, ... textAlpha: Int) {
    if (canvasW == lastLayoutCanvasW && purpose == lastLayoutPurpose && textAlpha == lastLayoutAlpha) return
    lastLayoutCanvasW = canvasW
    lastLayoutPurpose = purpose
    lastLayoutAlpha = textAlpha
    // ... 设置 paint color + alpha，构建 layout
}
```

## 总结修改

三次修改均在 `ParticleEngineCanvas.kt`：

| 位置 | 修改内容 |
|------|---------|
| L148-150 | `divineTextPaint.apply { color = Color.RED }` |
| L154-156 | `normalTextPaint.apply { color = Color.RED }` |
| `ensureLayouts` 方法 | 增加 `textAlpha` 入参和缓存，在构建 StaticLayout 前设置 paint.alpha |
| L295 | 调用 `ensureLayouts` 时传入 `textAlpha` |

这样修改后：
1. 文字基础颜色为纯红，不会出现黑色
2. 渐入渐出 alpha 动画正常
3. 不会每帧重建 layout（只在 alpha 变化时重建，变化频率等同于帧率——这是可接受的性能开销，因为文字渲染本身就只需要一次 native 调用）
