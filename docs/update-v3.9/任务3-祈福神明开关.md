# 任务3：祈福功能添加神明输入切换

## 问题

祈福功能缺少"添加神明"的选项，需要在输入祈福事件下方增加一个切换开关，打开后显示"神明"输入框。

## 修改文件

1. `app/src/main/java/com/example/karma/ui/prayer/PrayerViewModel.kt`
2. `app/src/main/java/com/example/karma/ui/prayer/PrayerScreen.kt`

## 修改方案

### Step 1: PrayerViewModel 新增状态和方法

在 `PrayerUiState` 中新增字段（约13-22行）：

```kotlin
val showDeityInput: Boolean = false,
val deity: String = "",
```

新增方法：

```kotlin
fun onToggleDeityInput() {
    _uiState.value = _uiState.value.copy(showDeityInput = !_uiState.value.showDeityInput)
}

fun onDeityChanged(text: String) {
    _uiState.value = _uiState.value.copy(deity = text)
}
```

### Step 2: 修改 `confirmPrayer()`

原记录格式：
```kotlin
repository.addHistoryEntry(-amount, "祈福：\n${state.purpose}", "prayer")
```

改为：如果 `deity` 非空，在事件文本末尾追加 `（神明：${deity}）`：

```kotlin
val suffix = if (state.deity.isNotBlank()) "（神明：${state.deity}）" else ""
repository.addHistoryEntry(-amount, "祈福：\n${state.purpose}$suffix", "prayer")
```

### Step 3: PrayerScreen UI 修改

在"祈福目的"输入框（约199行 `「  OutlinedTextField  」` 区域）之后、"Action buttons"（约202行）之前，**新增**如下代码：

```kotlin
Spacer(Modifier.height(16.dp))

// —— 神明切换开关 ——
Row(
    modifier = Modifier.fillMaxWidth(),
    horizontalArrangement = Arrangement.SpaceBetween,
    verticalAlignment = Alignment.CenterVertically,
) {
    Text(
        text = "添加神明",
        fontSize = 14.sp,
        fontWeight = FontWeight.Bold,
        color = Color(0xFFffd700),
    )
    Switch(
        checked = state.showDeityInput,
        onCheckedChange = { viewModel.onToggleDeityInput() },
        colors = SwitchDefaults.colors(
            checkedThumbColor = Color(0xFFffd700),
            checkedTrackColor = Color(0xFFffd700).copy(alpha = 0.3f),
        ),
    )
}

// —— 神明输入框（仅开关打开时显示）——
if (state.showDeityInput) {
    Spacer(Modifier.height(12.dp))
    Text(
        text = "神明",
        fontSize = 13.sp,
        color = Color(0xFF888888),
        modifier = Modifier.fillMaxWidth(),
    )
    Spacer(Modifier.height(4.dp))
    OutlinedTextField(
        value = state.deity,
        onValueChange = { viewModel.onDeityChanged(it) },
        placeholder = { Text("输入神明名称...", color = Color(0xFF666666)) },
        keyboardOptions = KeyboardOptions(imeAction = ImeAction.Default),
        textStyle = TextStyle(color = Color(0xFFff0000), fontSize = 16.sp),
        singleLine = true,
        shape = RoundedCornerShape(10.dp),
        colors = OutlinedTextFieldDefaults.colors(
            focusedBorderColor = Color(0xFFffd700),
            unfocusedBorderColor = BorderSubtle,
            cursorColor = Color(0xFFff0000),
            focusedContainerColor = ScoreBtnBg,
            unfocusedContainerColor = ScoreBtnBg,
        ),
        modifier = Modifier.fillMaxWidth(),
    )
}
```

**需要新增的 import**：`SwitchDefaults` 来自 `androidx.compose.material3.SwitchDefaults`（可能已在文件中）。

## 验证

1. 进入祈福页面，能看到"添加神明"开关（禁用状态）
2. 打开开关 → "神明"输入框出现，输入文字为纯红色
3. 关闭开关 → 神明输入框消失
4. 填写所有信息后确认 → 历史记录中的事件包含 `（神明：xxx）`
5. 不填写神明 → 历史记录格式和原来一致
