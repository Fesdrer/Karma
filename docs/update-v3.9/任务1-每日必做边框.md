# 任务1：每日必做事件添加天蓝色边框

## 问题

每日必做事件（未做状态）仅背景蓝色不够明显，需要在边缘添加不透明的天蓝色边框。

## 修改文件

- `app/src/main/java/com/example/karma/ui/main/components/EventPanel.kt`

## 定位

在 `EventPanel.kt` 的 `EventSection` composable（约306行），每个事件条目使用 `Box` 渲染，修饰符链顺序为：

```
.fillMaxWidth()                              ← 306
.padding(vertical = 1.dp)                    ← 307
.clip(RoundedCornerShape(7.dp))              ← 308
.then(border(2.dp, Gold) if isSelected)      ← 309-315
.background(when { deed/v title/ else })     ← 317-328
.padding(horizontal = 8.dp)                  ← 329
.defaultMinSize(minHeight = 13.dp)           ← 330
.fillMaxWidth()                              ← 331
.then(clickable if canSelect)                ← 332-337
```

## 修改方案

在 `deed != null && deed.vis == 0` 情况（每日必做、未做）添加一个天蓝色边框。

**具体修改**：在 `.background(...)` 之后、`.padding(horizontal = 8.dp)` 之前，对于 `deed.vis == 0` 的 case，追加：

```kotlin
.then(
    if (deed != null && deed.vis == 0) {
        Modifier.border(1.dp, Color(0xFF00D4FF).copy(alpha = 0.55f), RoundedCornerShape(7.dp))
    } else {
        Modifier
    }
)
```

**边框位置关键**：放在 `background` 之后（覆盖在背景之上）但 `padding` 之前（边框紧贴内容边缘，不撑大视觉尺寸）。

**颜色**：`0xFF00D4FF` 是亮天蓝色，`alpha = 0.55f` 使边框半透明不刺眼，和蓝色背景 `0xFF4488ff(α=0.15)` 配合。

## 修改后的修饰符链

```kotlin
.fillMaxWidth()
.padding(vertical = 1.dp)
.clip(RoundedCornerShape(7.dp))
.then(
    if (isSelected) {
        Modifier.border(2.dp, Color(0xFFffd700), RoundedCornerShape(7.dp))
    } else {
        Modifier
    }
)
.background(/* ... 同前 ... */)
// 👇 新增：天蓝色边框
.then(
    if (deed != null && deed.vis == 0) {
        Modifier.border(1.dp, Color(0xFF00D4FF).copy(alpha = 0.55f), RoundedCornerShape(7.dp))
    } else {
        Modifier
    }
)
.padding(horizontal = 8.dp)
.defaultMinSize(minHeight = 13.dp)
.fillMaxWidth()
.then(
    if (canSelect) {
        Modifier.clickable { onEventSelected(event) }
    } else {
        Modifier
    }
)
```

## 验证

1. 编译安装后，检查设置了每日必做的善业事件（未做状态）是否有天蓝色半透明边框
2. 已做状态（vis=1）无边框，选中状态（isSelected）保持金色边框
3. 事件框整体尺寸和周围间距不变
