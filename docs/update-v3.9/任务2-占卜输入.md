# 任务2：小六壬占卜、大衍筮法占卜添加输入框和业力记录

## 问题

进入占卜页面后没有输入"占卜的事情"和"扣分业力分数"的界面，占卜完成后也没有自动记录业力分数到历史记录。
同时 LuckAmplifier 需要跳过"占卜："前缀的事件，不计算运气增幅。

## 修改文件

1. `app/src/main/java/com/example/karma/ui/divination/DivinationScreen.kt` — 主入口，添加输入面板 + 记录逻辑
2. `app/src/main/java/com/example/karma/util/LuckAmplifier.kt` — 跳过我占卜"事件

## 不改的文件

- `DivinationViewModel.kt`（小六壬）— 保持纯净，不引入 repository
- `YarrowViewModel.kt`（大衍筮法）— 同上

## 方案设计

### 当前 DivinationScreen 结构分析

```
DivinationScreen
├── BackButton (tab=0,2时显示)
├── Crossfade(selectedTab) {
│   0 → 气运测试（纯随机数）
│   1 → YarrowViewModel + YarrowCanvas
│   2 → XiaoLiuRenContent (DivinationViewModel + 柱子/金线/输入/结果)
│   }
└── Bottom tab bar
```

当前没有任何 repository 引用或记录逻辑。

### UI 结构改动

在 Crossfade 外层添加一个条件判断：如果用户尚未输入"占卜事情"，则以全屏覆盖层显示输入面板；
一旦确认输入，隐藏该面板并显示 tabs。

状态图：
```
[进入占卜页面] → [显示占卜输入面板] → [用户输入事情+分数→确认] → [显示tab+开始占卜]
                                                                    ↓
                                                          [占卜完成→自动记录]
```

### 步骤

#### Step 1：DivinationScreen 中添加状态

```kotlin
var divinationTopic by remember { mutableStateOf("") }
var divinationCost by remember { mutableStateOf("") }
var divinationReady by remember { mutableStateOf(false) }
```

`divinationReady == false` 时显示输入面板，`true` 时显示正常 tab 内容。

记录状态（防止重复记录）：
```kotlin
var xlrRecorded by remember { mutableStateOf(false) }  // 小六壬是否已记录
var yarrowRecorded by remember { mutableStateOf(false) } // 大衍筮法是否已记录
```

#### Step 2：输入面板 UI

在 Crossfade 之前、BackButton 之后、当 `!divinationReady` 时，显示一个布局：

```kotlin
Box(fillMaxSize, centerAlignment) {
    Column(0.9f宽, 圆角面板, 深色背景) {
        // 标题 "🔮 占卜"
        // (金色，Serif，24sp)
        
        // —— 输入占卜事情 ——
        Text("占卜的事情", 13sp, 灰)
        OutlinedTextField(
            value = divinationTopic,
            onValueChange = { divinationTopic = it },
            placeholder = "输入占卜事情...",
            textStyle = TextStyle(color = Color(0xFFff0000), fontFamily = FontFamily.Serif, fontSize = 16.sp),
            colors = /* 边框金色/透明内部/光标红色 */
        )
        
        Spacer(16dp)
        
        // —— 输入业力分数 ——
        Text("本次扣除业力分数", 13sp, 灰)
        OutlinedTextField(
            value = divinationCost,
            onValueChange = { /* 只允许输入正数/整数 */ divinationCost = it.filter { c -> c.isDigit() } },
            placeholder = "输入正数...",
            keyboardOptions = KeyboardOptions(keyboardType = KeyboardType.Number),
            textStyle = TextStyle(color = Color(0xFFe0e0e0), fontFamily = FontFamily.Serif, fontSize = 16.sp),
        )
        
        Spacer(20dp)
        
        // 确认按钮
        Button("开始占卜", onClick = {
            if (divinationTopic.isBlank() || divinationCost.toFloatOrNull() == null || divinationCost.toFloat() <= 0f) {
                // Toast提示
            } else {
                divinationReady = true
            }
        })
    }
}
```

**文本颜色说明**：
- "占卜的事情"输入框文字 = 纯红色 `0xFFff0000`（参照祈福目的输入框样式）
- "业力分数"输入框文字 = 默认浅色 `0xFFe0e0e0`（数字输入不需高亮）

#### Step 3：监听占卜完成→记录

在小六壬内容区旁边（同样在 Crossfade 内部 tab=2 分支）添加 LaunchedEffect：

```kotlin
// 小六壬记录：在 COMPLETE 阶段且未记录时触发
LaunchedEffect(xlrState.animationPhase) {
    if (xlrState.animationPhase == AnimationPhase.COMPLETE && !xlrRecorded) {
        val cost = divinationCost.toFloatOrNull() ?: return@LaunchedEffect
        appContainer.repository.addHistoryEntry(-cost, "占卜：${divinationTopic}", "divination")
        xlrRecorded = true
    }
}
```

在大衍筮法区域旁边添加（tab=1 分支）：

```kotlin
// 大衍筮法记录：在 showResult == true 且未记录时触发
LaunchedEffect(ys.showResult) {
    if (ys.showResult && !yarrowRecorded) {
        val cost = divinationCost.toFloatOrNull() ?: return@LaunchedEffect
        appContainer.repository.addHistoryEntry(-cost, "占卜：${divinationTopic}", "divination")
        yarrowRecorded = true
    }
}
```

**重置**：当用户切换 tab 或进行新的占卜时不要重复记录——通过 `xlrRecorded` / `yarrowRecorded` 标记确保只记录一次。

#### Step 4：LuckAmplifier 跳过"占卜："事件

文件 `app/src/main/java/com/example/karma/util/LuckAmplifier.kt`，第150行附近：

```kotlin
// 修改前：
if (pI.event.startsWith("善果：") || pI.event.startsWith("祈福：") || pI.event == "业力衰减") continue

// 修改后：
if (pI.event.startsWith("善果：") || pI.event.startsWith("祈福：") || pI.event.startsWith("占卜：") || pI.event == "业力衰减") continue
```
