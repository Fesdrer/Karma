# Karma v3.2 — 占卜页面三标签框架

## Context

占卜页面底部改为三标签切换：气运测试（默认）/ 大衍筮法 / 小六壬，后两者暂为空白框架。

## 修改

**DivinationScreen.kt** 唯一改动文件：
1. 新增 `selectedTab` 状态（0/1/2）
2. 中间内容区根据 `selectedTab` 切换：
   - 0 = 气运测试（当前随机页面，result + 开始按钮）
   - 1 = 大衍筮法（空白占位）
   - 2 = 小六壬（空白占位）
3. 底部替换为三标签栏：
   - 当前选中标签高亮（蓝底白字），未选中暗色
   - 等宽分布，`Arrangement.SpaceEvenly`
   - 背景深色横条
4. "开始"按钮从底部移到气运测试内容区内

## 验证
- 默认显示气运测试
- 点击大衍筮法/小六壬切换到空白页
- 点击气运测试切回随机页面
