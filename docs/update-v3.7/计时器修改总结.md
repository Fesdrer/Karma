# v3.7 计时器 UI 改造：内嵌式计时控制

## 目标

计时器不再全屏独占，改为内嵌在主页面 EventPanel 底部，用户可在计时时自由查看设置、历史等其他功能。

## 改动文件

| 文件 | 操作 | 说明 |
|------|------|------|
| `ui/main/components/EventPanel.kt` | 修改 | 底部计时按钮替换为 2 倍高度计时控制栏 |
| `ui/main/MainScreen.kt` | 修改 | 移除 `onNavigateToTimer` 回调，添加停止逻辑 |
| `ui/navigation/NavGraph.kt` | 修改 | 移除 TimerScreen composable 注册 |
| `ui/navigation/Screen.kt` | 修改 | 移除 `Timer` 路由定义 |
| `ui/timer/TimerScreen.kt` | 删除 | 不再使用 |
| `ui/timer/TimerViewModel.kt` | 删除 | 停止计算逻辑移入 MainScreen |

## 未改动

- **TimerService.kt** — 完全不变，全局单例 StateFlow 照常工作
- **Footer.kt** — 不变，计时时可自由点击设置/历史等
- **SettingsScreen.kt / HistoryScreen.kt / PrayerScreen.kt / DivinationScreen.kt** — 不受影响
- **MainViewModel.kt** — 不变

## 交互流程

```
空闲态（80dp）:
┌────────────────────────┐
│    ▶ 开始计时  +5 分    │ ← 样式不变
└────────────────────────┘

计时态（同高 80dp，内部变化）:
┌────────────────────────┐
│       01:23:45         │ ← 金色 21sp
├───────────┬────────────┤
│   [ || ]  │   [ ■ ]    │ ← 固定 56×34dp 按钮
└───────────┴────────────┘
```

| 状态 | 时间显示 | 左图标 | 左点击 | 右图标 | 右点击 |
|------|---------|--------|--------|--------|--------|
| IDLE | — | — | 点击→启动计时 | — | — |
| RUNNING | 当前时间 | \|\| | 暂停 | ■ | 停止+写DB |
| PAUSED | 暂停时间 | ▶ | 继续 | ■ | 停止+写DB |

## UI 细节

- **字体大小**：21sp（原 28sp 的 0.75）
- **图标**：自定义 Composable 绘制（不依赖 Unicode emoji，无蓝框）
  - 暂停：两个白色圆角竖条（3×14dp，间距 3dp）
  - 继续：白色三角形（Canvas Path）
  - 停止：白色圆角方块（14×14dp）
- **按钮**：固定尺寸 56×34dp，内容居中，切换不改变大小
- **颜色**：暂停/继续按钮底色 `#b8860b`，停止按钮底色 `#333333`
- **页面切换**：`displayMs` 从 `timerState.currentElapsedMs()` 初始化，回来直接显示正确时间

## 验证

1. 选分数+事件 → 点击"▶ 开始计时" → 按钮原地展开为 80dp 高，显示时间 + \|\| / ■ 图标
2. 点击 \|\| → 时间暂停，图标变为 ▶
3. 点击 ▶ → 时间继续，图标变回 \|\|
4. 计时中点 Footer"设置" → 正常跳转，通知栏计时继续
5. 返回主页 → 时间显示正确（不闪 00:00:00）
6. 点击 ■ → 停止计时写 DB，恢复空闲按钮
