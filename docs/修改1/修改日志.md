## 2026-06-15 修复：UI缩放 + 偶数标尺 + 缩放崩溃

> **构造修正**: 初始使用 `density.density` 报错，`DrawScope` 中 `density` 直接为 `Float` 类型，修正为 `val densityFactor = density`

### 修改清单

#### 1. 历史图表双指缩放崩溃修复（严重）
- **文件**: `app/src/main/java/com/example/karma/ui/history/HistoryChartCanvas.kt`
- **问题**: `detectTransformGestures` 中 `coerceIn` 在视口未初始化时抛出 `IllegalArgumentException`
- **方案**: 在计算 `range` 后添加守卫 `if (range <= 0.0 || vp.maxTimeRange < vp.minTimeRange)`

#### 2. 左边 ScorePanel 密度感知缩放
- **文件**: `app/src/main/java/com/example/karma/ui/main/components/ScorePanel.kt`
- **方案**: 添加 `val densityFactor = density`，所有像素值乘以密度因子
  - 红色选择圆: 8px → 8×density px（约 8dp）
  - "0" 标签: 26px → 26×density px（约 26dp）
  - 整数标签: 22px → 22×density px
  - 半值标签: 18px → 18×density px

#### 3. 中心轴添加 ±10 范围偶数标尺
- **文件**: `app/src/main/java/com/example/karma/ui/main/components/AxisCanvas.kt`
- **方案**: 每 2 格一个偶数刻度，与现有刻度样式一致
- **示例**: 当前分数 39.5 时显示 30,32,34,...,48

## 2026-06-15 调整：映射指数更新 + 轴标签缩小

### 修改 1：压缩指数重新计算（+15 位于 1/4 位置）
- **文件**: `app/src/main/java/com/example/karma/ui/main/components/AxisCanvas.kt:23`
- **旧值**: `AXIS_COMPRESSION_EXPONENT = 0.2314f`（旧：+5 在 1/4）
- **新值**: `AXIS_COMPRESSION_EXPONENT = 0.3654f`（新：+15 在 1/4）
- **推导**: `(15/100)^exponent = 0.5` → `exponent = ln(0.5)/ln(0.15) = 0.3654`
- **效果**: 近中心分数压缩更大 → 中间可显示更多分数（更密集）

### 修改 2：轴上标签字体缩小至约 0.8x
- **文件**: `app/src/main/java/com/example/karma/ui/main/components/AxisCanvas.kt`
- 主刻度标签: 24f → 19f（≈0.79x）
- 偶数刻度标签: 24f → 19f
- 范围标签(顶/底): 20f → 16f（0.8x）
- 当前分数标签: 26f → 21f（≈0.81x）
