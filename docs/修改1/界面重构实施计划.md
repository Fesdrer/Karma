# 业力值模拟器 - 界面重构实施计划

## 上下文

该应用使用 Jetpack Compose (Material3) + Kotlin，UI 完全自绘 Canvas。当前中间分数轴使用 `pow(absD, 0.6)` 非线性映射，左边分数使用预设网格按钮，历史屏幕的 6 个按钮需要水平滚动才能全部显示且图表不支持缩放。用户希望：（1）让中间轴的非线性更极端（中间更疏、两边更密，+5 映射到 1/4 高度）；（2）将左侧分数选择改为竖向拖动轴（±0.5~±6，红色圆圈指示器）；（3）历史屏幕 6 个按钮全部可见并支持图表缩放。

## 变更 1：AxisCanvas.kt — 更极端的非线性映射

**修改文件：** `app/src/main/java/com/example/karma/ui/main/components/AxisCanvas.kt`

### 方案

当前 `scoreToY` 使用 `pow(absD, 0.6)` 映射。用户要求 `+5` 映射到 1/4 高度位置（现为 ~41.7%），即需要该点满足：

```
scoreToY(centerScore + 5) = h/4
```

映射公式：`offset = (absD)^e * halfH / (AXIS_DISPLAY_RANGE)^e`

解方程 `(5/100)^e = 0.5` → `e = ln(0.5) / ln(0.05) ≈ 0.2314`

### 具体修改

1. 在顶部添加常量：
   ```kotlin
   private const val AXIS_COMPRESSION_EXPONENT = 0.2314f
   ```

2. 修改 `scoreToY` 函数：
   - 将 `absD.toDouble().pow(0.6)` 替换为 `absD.toDouble().pow(AXIS_COMPRESSION_EXPONENT.toDouble())`
   - 将 `AXIS_DISPLAY_RANGE.toDouble().pow(0.6)` 替换为 `AXIS_DISPLAY_RANGE.toDouble().pow(AXIS_COMPRESSION_EXPONENT.toDouble())`

3. 刻度标签验证：`+5` 将在 1/4 位置，`±100` 仍在边缘，`±10`、`±20`、`±50` 等靠近边缘但不会重叠，现有 `idealTicks=16` 逻辑保持。

### 未修改的部分

- `AXIS_DISPLAY_RANGE = 100f` 保持不变
- 动画、背景、段位色带、指针等逻辑不变

#### 分数→Y 映射

```kotlin
private fun scoreToCanvasY(score: Float, canvasH: Float): Float {
    val range = 6f
    val usableHeight = canvasH * 0.7f  // 留上下 15% 边距
    val topY = canvasH * 0.15f
    val ratio = (score / range).coerceIn(-1f, 1f)
    return topY + usableHeight * (0.5f - ratio * 0.5f)
}
```

#### 位置捕捉

```kotlin
private fun snapToHalf(v: Float): Float = kotlin.math.round(v * 2f) / 2f
// 约束到 ±6
val clamped = snapToHalf(v).coerceIn(-6f, 6f)
```

## 变更 3：HistoryScreen / HistoryChartCanvas — 全部按钮可见 + 缩放

**修改文件：**
- `app/src/main/java/com/example/karma/ui/history/HistoryScreen.kt` — 去掉 horizontalScroll，紧凑布局
- `app/src/main/java/com/example/karma/ui/history/HistoryChartCanvas.kt` — 添加双指缩放 + 拖拽平移

### 3a：6 个按钮同时显示

在 HistoryScreen.kt 中，当前布局是同一行内左半边放"← 返回"+"历史记录"标题，右半边用 `horizontalScroll` 放 6 个按钮。

根据用户手机 1224×2700 (密度 ≈ 2.77, dp 宽 ≈ 442dp)，重新设计布局为**两行结构**，让所有按钮无需滚动即可完整显示：

**第一行**：左：`← 返回` + `历史记录` 标题 | 右：`日` `周` `月` 视图切换按钮
**第二行**：右对齐/居中对齐：`CSV` `JSON` `导入` 三个操作按钮

具体修改：
1. 将原来一个 Row 拆分为上下两个 Row
2. 第一行使用 `Arrangement.SpaceBetween` 让左侧标题和右侧视图按钮分居两端
3. 第二行放置导出/导入按钮，使用 `Arrangement.End` 或 `Arrangement.Center` 对齐
4. 按钮内边距从 `padding(horizontal = 12.dp, vertical = 6.dp)` 改为 `padding(horizontal = 10.dp, vertical = 5.dp)`
5. 字体从 `14.sp` 改为 `13.sp`

dp 占用计算（442dp 总宽度，左右 padding 各 16dp → 可用宽度 410dp）：
- 第一行左侧（← 返回 + Spacer(10dp) + 历史记录）≈ 48 + 10 + 56 = ~114dp
- 第一行右侧 3 个视图按钮（日/周/月）：(20 + 13) × 3 + 4dpx2间隙 = ~107dp → 总计 114+107=221 < 410 ✓
- 第二行 3 个操作按钮（CSV/JSON/导入）：(20 + 26) + (20 + 32) + (20 + 22) + 4dp×2间隙 = ~152dp < 410 ✓

### 3b：图表缩放

#### ChartViewport 修改

```kotlin
data class ChartViewport(
    var viewStart: Double = 0.0,
    var viewEnd: Double = 0.0,
    var yMin: Float = 0f,
    var yMax: Float = 10f,
    var minTimeRange: Double = 3600000.0,  // 最小 1 小时
    var maxTimeRange: Double = 0.0,        // 初始化时设为全范围
)
```

#### 手势处理

HistoryChartCanvas 中为 Canvas 添加第二个 `pointerInput` 块来处理缩放：

```kotlin
.pointerInput(Unit) {
    detectTransformGestures { centroid, _, zoom, _ ->
        if (pts.size < 2) return@detectTransformGestures
        val vp = viewport
        val center = centroid.x
        
        // 将缩放中心从屏幕坐标转换到时间坐标
        val plotW = size.width.toFloat() - PAD_LEFT - PAD_RIGHT
        val timeAtCenter = vp.viewStart + ((center - PAD_LEFT) / plotW) * (vp.viewEnd - vp.viewStart)
        
        // 缩放时间范围
        val newRange = (vp.viewEnd - vp.viewStart) / zoom
        val clampedRange = newRange.coerceIn(vp.minTimeRange, vp.maxTimeRange)
        
        vp.viewStart = timeAtCenter - (timeAtCenter - vp.viewStart) / zoom * (clampedRange / newRange)
        vp.viewEnd = vp.viewStart + clampedRange
        
        // 自动适配 Y 轴
        autoFitYAxis(pts, vp)
    }
}
```

- `detectTransformGestures` 与已有的 `detectTapGestures` 不会冲突（单指点击 vs 双指缩放）
- 添加 `autoFitYAxis` 辅助函数：根据当前时间窗口内的数据点计算 Y 范围

#### 拖拽平移

在 `detectTransformGestures` 的 `pan` 参数中处理横向平移：
```kotlin
// 处理水平拖拽
val panDelta = pan.x
val timeDelta = -panDelta / plotW * (vp.viewEnd - vp.viewStart)
val newStart = vp.viewStart + timeDelta
val newEnd = vp.viewEnd + timeDelta
if (newStart >= 0 && newEnd <= vp.maxTimeRange) {
    vp.viewStart = newStart
    vp.viewEnd = newEnd
    autoFitYAxis(pts, vp)
}
```

#### 实时渲染保证

Canvas 本身在每帧重绘，当 `viewport` 的 var 值变化时，Canvas 的 `draw` 块重新执行。为强制重组，可以在 `key(points.size)` 或使用 `snapshotFlow`：

```kotlin
var viewportVersion by remember { mutableIntStateOf(0) }
// 缩放时 +1
// Canvas 的 key 或依赖中加入 viewportVersion
```

或者在 Canvas 内直接读取 `viewport.viewStart` 等 var（由于它们是 `draw` 闭包内捕获的可变引用，值变化不会触发重组）。更稳妥：在 `pointerInput` 修改 viewport 后，修改一个 `mutableStateOf` 触发的 counter：

```kotlin
val redrawTrigger = remember { mutableIntStateOf(0) }
// transform gesture 中：redrawTrigger.intValue++
// Canvas modifier 中加入 .drawWithContent { ... } 或直接用 key
```
