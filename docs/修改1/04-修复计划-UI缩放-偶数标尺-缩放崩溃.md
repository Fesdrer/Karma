# 修复计划：UI缩放 + 中心轴偶数标尺 + 历史图表缩放崩溃

## Context

三个问题来自上一轮修改完成后的测试（手机 1224×2700）：

1. **左边分数面板元素太小** — Canvas 绘制的元素使用原始像素值，在高密度屏上物理尺寸过小
2. **中心轴标尺不够精细** — 当前分数±10 范围内缺少偶数整数参考标尺
3. **历史图表双指缩放闪退** — `coerceIn` 在视口未初始化时抛出 `IllegalArgumentException`

---

## Issue 1: 左边 ScorePanel 放大（密度感知渲染）

**文件**: `app/src/main/java/com/example/karma/ui/main/components/ScorePanel.kt`

**根因**: `ScoreAxisView` 中 Canvas 绘制的圆、文字、刻度线均使用硬编码像素值（如 `radius = 8f`, `textSize = 26f`）。在密度 ~3.0 的 1224×2700 屏幕上，8 像素 ≈ 2.7dp，远小于预期。

**方案**: 在 Canvas lambda 中获取密度因子 `val densityFactor = density.density` (Float)，将所有视觉元素的像素值乘以该因子。

### 具体修改

| 行号(原) | 当前代码 | 修改后 |
|---------|---------|--------|
| 132 | `val h = size.height` | 在其后添加 `val densityFactor = density.density` |
| 151 | `strokeWidth = 1.5f` | `strokeWidth = 1.5f * densityFactor` |
| 159 | `val tickLen = if (isInteger) 8f else 5f` | `= if (isInteger) 8f * densityFactor else 5f * densityFactor` |
| 181 | `val labelSize = if (tickValue == 0f) 26f else if (isInteger) 22f else 18f` | `= if (tickValue == 0f) 26f * densityFactor else if (isInteger) 22f * densityFactor else 18f * densityFactor` |
| 188 | `axisX + 6f` | `axisX + 6f * densityFactor` |
| 213 | `radius = 14f` (外发光) | `radius = 14f * densityFactor` |
| 219 | `radius = 8f` (主圆) | `radius = 8f * densityFactor` |
| 225 | `radius = 3f` (高光) | `radius = 3f * densityFactor` |
| 226 | `Offset(axisX - 1.5f, circleY - 1.5f)` | `Offset(axisX - 1.5f * densityFactor, circleY - 1.5f * densityFactor)` |

## Issue 2: 中心轴 ±10 范围显示偶数标尺

**文件**: `app/src/main/java/com/example/karma/ui/main/components/AxisCanvas.kt`

**方案**: 在现有刻度绘制完成后（line 148 之后）、轴线绘制前（line 150 之前），插入一个新的刻度绘制块。

### 新增代码块（~20行）

```kotlin
        // ---- 偶数参考标尺：当前分数±10范围内，每2格一个 ----
        val evenMin = ceil((centerScore - 10f) / 2f).toInt() * 2
        val evenMax = floor((centerScore + 10f) / 2f).toInt() * 2
        val evenTickLen = 12f * densityFactor
        var evenTick = evenMin
        while (evenTick <= evenMax) {
            val y = scoreToY(evenTick.toFloat(), centerScore, halfH, h)
            if (y in -8f..h + 8f) {
                drawLine(...)
                drawContext.canvas.nativeCanvas.drawText(evenTick.toString(), ...)
            }
            evenTick += 2
        }
```

偶数标尺亮度更高（alpha=0.55 vs 现有 0.25），长度更长（12dp vs 7dp），叠加在现有刻度上方。

## Issue 3 (严重): 历史图表双指缩放闪退

**文件**: `app/src/main/java/com/example/karma/ui/history/HistoryChartCanvas.kt`

**根因**: `detectTransformGestures` handler 第 111 行的 `coerceIn` 在视口未初始化时抛出 `IllegalArgumentException`：
- `viewStart = viewEnd = 0.0` → `range = 0.0`
- `minTimeRange(3600000.0) > maxTimeRange(0.0)` → 空范围

**修改**: 在计算 `range` 后（line 105）添加一行守卫：
```kotlin
if (range <= 0.0 || vp.maxTimeRange < vp.minTimeRange) return@detectTransformGestures
```

1. **Issue 1**: 1224×2700 手机上，红色选择圆约 8dp 直径，"0" 标签约 26dp 高
