# 步骤10：工具与收尾

## 工具类

### CsvParser.kt
**结论**: 未单独创建文件。CSV 解析逻辑直接实现在 `KarmaRepository.kt` 中：
- `exportCsv()` — BOM 头 + 引号转义 + timestamp,delta,event,totalAfter,type 格式
- `parseCsvLine()` — 简易 RFC 4180 解析（处理引号字段内逗号）
- `importCsv()` — 排序按时间戳 + 重算 totalAfter
- `exportJson()` — GsonBuilder prettyPrint
- `importJson()` — 解析 Map 结构 + 批量插入

### RankCalculator.kt
- **位置**: `util/RankCalculator.kt`
- **功能**: 根据分数查找对应段位，返回 `Rank?`（负分返回 null）
- **实现**: `Rank.RANKS.find { score >= it.min && score < it.max }`
