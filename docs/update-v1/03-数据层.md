# 步骤3: 数据层

## 目标
实现完整的 Room 数据库层，替代 HTML 的 localStorage。

## 涉及文件
- `data/model/Rank.kt` — 段位数据类 + 9 阶常量
- `data/model/HistoryEntry.kt` — 领域模型
- `data/model/ViewMode.kt` — 视图模式枚举
- `data/local/entity/HistoryEntryEntity.kt` — Room 实体 (history_entries 表)
- `data/local/entity/KarmaSettingsEntity.kt` — Room 实体 (karma_settings 单行表)
- `data/local/dao/HistoryEntryDao.kt` — 历史记录 DAO
- `data/local/dao/KarmaSettingsDao.kt` — 设置 DAO
- `data/local/converter/Converters.kt` — Gson TypeConverters
- `data/local/KarmaDatabase.kt` — Room 数据库单例
- `data/repository/KarmaRepository.kt` — 单一数据入口
- `util/RankCalculator.kt` — 段位查找工具

## 决策记录

### 数据库设计
- **单行表** karma_settings：使用 id=1 的单行存储 totalScore、scorePresets、eventPresets
- **List 字段**通过 Gson TypeConverters 序列化为 JSON 字符串存储
- **历史记录上限** 2000 条，通过 `trimOldest()` 在每次插入时检查并裁切
- **导入导出**：Repository 中实现了 JSON/CSV 的格式解析和写入，CSV 使用简单引号转义

### 重要逻辑
- `addHistoryEntry` 原子性地同时更新 totalScore 和插入历史记录
- 导入 CSV 时按时间戳排序并重算 totalAfter
- JSON 导入使用 Gson 解析 Map 结构，包含格式校验
