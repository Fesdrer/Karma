# 步骤9：祈福屏幕

## 文件创建

### ParticleEngineCanvas.kt
- **位置**: `ui/prayer/ParticleEngineCanvas.kt`
- **功能**: Compose Canvas 粒子系统，4 级特效（基于段位选择 Tier 0-3）
- **粒子类型**:
  - `KarmaThread` — Bezier 曲线光线，从中心向外生长
  - `ExpandingRing` — 红色膨胀光环
  - `Spark` — 小火花粒子（Tier 2+）
  - `RuneParticle` — 符文粒子（Tier 3/玖阶专属）
- **Tier 数据**:
  | 等级 | 线程数 | 光环数 | 火花数 | 持续时间 |
  |------|--------|--------|--------|----------|
  | 0 (壹~叁阶) | 30 | 2 | 0 | 3.2s |
  | 1 (肆~陆阶) | 50 | 4 | 25 | 4.2s |
  | 2 (柒~捌阶) | 80 | 6 | 65 | 5.2s |
  | 3 (玖阶) | 150 | 12 | 160 | 7.0s |
- **绘制层序**: 暗色背景 → 神圣光晕(玖阶) → Bezier 线程 → 膨胀光环 → 金色光环(玖阶) → 火花 → 符文(玖阶) → 文字层
- **帧循环**: `LaunchedEffect` + `withFrameMillis` + `mutableIntStateOf` 帧计数器触发 Canvas 重绘

### PrayerViewModel.kt
- **位置**: `ui/prayer/PrayerViewModel.kt`
- **状态**: `amount`, `purpose`, `showForm`, `isAnimating`, `totalScore`, `rankLevel`, `errorMessage`
- **业务逻辑**:
  - 金额必须为正数
  - 祈福目的不能为空
  - 总分需 ≥ 30 分才能祈福
  - 确认后调用 `repository.addHistoryEntry(-amount, "祈福：...", "prayer")` 扣减分

### PrayerScreen.kt
- **位置**: `ui/prayer/PrayerScreen.kt`
- **布局**: 全屏半透明黑色覆盖层
- **表单**: 输入扣减分数 + 「」括弧装饰的祈福目的输入框 + 取消/确认按钮
- **确认后**: 表单隐藏，粒子动画全屏播放，结束后自动返回

## NavGraph 接入
PrayerScreen 在 NavGraph 中已注册路由，`MainScreen` 的 Footer 在总分≥30 时激活祈福按钮。

## 编译问题与修复
1. **`Arrangement` 未导入** — PrayerScreen 使用 `Arrangement.spacedBy` 但缺少导入，且误写了一个伪 `@Composable private fun Arrangement()` 函数来掩盖。修复：添加 `import Arrangement`，删除伪函数。
2. **`withFrameMillis` 未导入** — 缺少 `import androidx.compose.runtime.withFrameMillis`
3. **`initialize` 函数重复** — `ParticleState` 类中同时存在成员函数和扩展函数，成员函数（空实现）遮蔽了扩展函数（完整实现），导致粒子从未初始化。修复：合并为一个类成员方法 `initializeParticles()`。
4. **粒子中心硬编码** — 粒子初始中心为 (500, 500)，与 Canvas 实际尺寸无关。修复：在 Canvas 绘制时设置 `state.cx = cx; state.cy = cy`。

## 与 HTML 原版的差异
- HTML 使用 `requestAnimationFrame`，Compose 使用 `withFrameMillis`，效果一致
- HTML 的 `setTimeout` 延迟通过粒子对象的 `delay` 字段在帧循环中判断
- HTML 的 CSS 覆盖层效果用 Compose `Box` + `Color.Black.copy(alpha = 0.85f)` 实现
- 文字绘制使用 `nativeCanvas.drawText` + `android.graphics.Paint` 而非 Compose `Text`，因 Canvas 内部无法直接使用 `Text` composable
