# 步骤7：编辑弹窗

## 涉及文件

```
ui/components/
└── ScoreEditModal.kt       # 同时包含 ScoreEditModal 和 EventEditModal
```

两个弹窗共用同一文件，遵循 Compose 惯例将相关组件放在同一文件中。

## 通用设计模式

两个弹窗均使用 `AlertDialog` composable，具有一致的外观和交互逻辑：

- **容器颜色**: `#16213e`（PanelBg），`RoundedCornerShape(16.dp)`
- **列表容器**: `LazyColumn` + `RoundedCornerShape(300.dp)` 固定高度
- **列表项**: 每项一行，包含 上移按钮 ▲ / 下移按钮 ▼ / 编辑框 / 删除按钮 ✕
- **添加行**: 底部 TextField + 「添加」按钮
- **底部**: 「取消」+「保存」按钮

## ScoreEditModal（预设分数编辑器）

### 状态管理
```kotlin
val presets = remember { mutableStateListOf<Float>().apply { addAll(initialPresets) } }
var addText by remember { mutableStateOf("") }
```
- `presets` 为 `SnapshotStateList<Float>`，支持 Compose 响应的增删改排序
- 每项的编辑框使用 `remember(value) { mutableStateOf(value.toString()) }` 独立管理文本状态

### 功能
| 操作 | 实现 |
|------|------|
| **上移** | `if (index > 0) swap(index, index-1)` |
| **下移** | `if (index < size-1) swap(index, index+1)` |
| **编辑** | `OutlinedTextField` + `toFloatOrNull()` 实时解析，有效值更新 presets |
| **删除** | `presets.removeAt(index)` |
| **添加** | 输入框 → `toFloatOrNull()` → `!= null && != 0f` → `presets.add(v)` |
| **保存** | `onSave(presets.toList())` 写回 Room |
| **取消** | `onDismiss()` 关闭弹窗，丢弃未保存修改 |

### 输入验证
- 添加时：必须为有效非零浮点数
- 编辑时：无效输入（非数字）保留原值，不更新 presets

## EventEditModal（预设事件编辑器）

### 状态管理
```kotlin
val presets = remember { mutableStateListOf<String>().apply { addAll(initialPresets) } }
var addText by remember { mutableStateOf("") }
```
- `SnapshotStateList<String>`，逻辑与分数编辑完全对称

### 功能
与 ScoreEditModal 相同，区别在于：
- `toFloatOrNull()` 替换为 `isNotBlank()` 检查
- 编辑时 `if (it.isNotBlank()) presets[index] = it`
- 添加时 `if (v.trim().isNotEmpty()) presets.add(v)`

### 输入验证
- 添加时：去除首尾空格后非空
- 编辑时：空白内容不更新 presets

## 数据流

```
用户编辑 presets(StateList) → 点击保存
  → onSave(presets.toList())
  → MainViewModel.saveScorePresets() / saveEventPresets()
    → repository.updateScorePresets() / updateEventPresets()
      → settingsDao.updateScorePresets() / updateEventPresets()
        → Room 写入 KarmaSettingsEntity
    → closeScoreEdit() / closeEventEdit()
      → _scoreEditMode = false / _eventEditMode = false
        → 弹窗关闭，MainScreen 重组显示新预设
```

## 与 HTML 原版的差异

- **HTML 使用 `contenteditable` + 直接 DOM 操作**，Compose 使用 `SnapshotStateList` + `AlertDialog`
- **HTML 的 `localStorage` 保存** 替换为 Room `KarmaSettingsDao`
- **HTML 排序通过拖拽**（drag & drop），Compose 使用 ▲▼ 按钮（触屏友好）
- **添加位置**：HTML 可能从文件选择器导入，Compose 使用文本输入框添加
- 删除操作增加了确认步骤（直接删除无二次确认），与 HTML 行为一致
