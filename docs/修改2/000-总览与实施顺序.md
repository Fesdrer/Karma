# 修改2 — 总览与实施顺序

## 三大功能

1. **设置界面** — Footer ⚙ 进入，分段卡片控制所有视觉参数 + 事件列表编辑 + 业力衰减配置
2. **历史记录改造** — 日/周/月/全部四模式，从聚合改为时间范围过滤显示全部记录
3. **业力衰减** — 应用启动时检查补扣，各阶位可配扣除量

## 关键设计决策（已确认）

| 决策 | 选择 |
|------|------|
| 设置入口 | Footer 右侧 ⚙ 齿轮图标按钮 |
| 设置保存方式 | 编辑期持有本地副本，点击保存统一写 Room |
| 衰减触发 | 应用启动时检查补扣（非 AlarmManager） |
| 衰减记录类型 | `type = "decay"`，event = "业力衰减" |
| 未使用字段 | `scorePresets` 保留在 Entity 中不移除（避免复杂 Migration） |
| 参数传递 | MainUiState 展开 settings 字段，逐层透传（非传 Entity 对象） |

## 验证方式

每完成一个 Phase 执行 `./gradlew assembleDebug` 确保编译通过。
