## Context

1. 增设独立设置界面，让所有视觉参数可调

### 关键交互细节

**疏密程度 Slider 的设计原理：**
- 当前 AxisCanvas 使用映射公式 `pixel_offset = (|d|/100)^0.3654 * halfH`
- 设置页面的 Slider 不直接暴露指数，而是暴露**"上方 1/4 高度处显示的分数偏移值"**（默认为 +15）
- 用户从 +2（中间极稀疏，exp≈0.174）滑动到 +50（线性，exp=1.0）
- 保存时将偏移值用公式 `exp = ln(0.5) / ln(value/100)` 转换为指数

**事件列表：**
- 采用多行 `OutlinedTextField`（`singleLine = false`，`minLines = 6`）
- 保存时按行拆分 `text.split("\n").map { it.trim() }.filter { it.isNotEmpty() }`
- 不需要单独的添加/删除按钮，编辑文本框本身即增删事件

**业力衰减的各阶位扣除量：**
- 每行使用两个紧凑的 `Row`：左侧显示阶位名称 + 颜色小圆点，右侧用 [-]/[+] 微调按钮 + 数字
- 步长为 1，范围 0~10（设为 0 即该阶位不扣除）
- 总开关控制整个衰减机制是否启用

**颜色选择交互：**
- 刻度颜色 + 阶位颜色：采用 `AlertDialog` 内显示色块网格（3×4 = 12 预设色）
- 预设色板：白、浅灰、深灰、金、蓝、红、绿、橙、青、紫、粉、棕

## 三、业力衰减机制设计

### 3.1 触发时机（已确认方案）

| 方案 | 机制 | 优点 |
|------|------|------|
| **A（已确认）** 应用启动时检查补扣 | MainViewModel/Application 初始化时检查 `lastDecayDate`，若 != 今天则补扣错过多天 | 简单可靠，无权限问题，兼容各 Android ROM |

**实现位置**（双重触发确保可靠性）：
1. `MainViewModel.init{}` — 用户打开主屏时触发
2. `KarmaApplication.onCreate()` — App 进程启动时触发（应对从通知栏等入口进入）

**扣后提示**：补扣完成后通过 `_message` StateFlow 弹出 Snackbar：「业力衰减：本次共扣除 X 分」

### 3.2 扣除逻辑

```kotlin
suspend fun applyDecay(): Int {  // 返回本次扣除的总分数
    val settings = settingsDao.getSettingsOnce() ?: KarmaSettingsEntity()
    if (!settings.decayEnabled) return 0
    
    val today = LocalDate.now().toString()  // "2026-06-15"
    if (settings.lastDecayDate == today) return 0  // 今天已扣过
    
    // 计算需要补扣的天数
    val lastDate = if (settings.lastDecayDate.isEmpty()) {
        // 从未扣除过：从第一条历史记录那天开始
        val firstEntry = historyDao.getOldestEntry()
        if (firstEntry == null) {
            // 没有任何记录，从今天开始
            settingsDao.updateLastDecayDate(today)
            return 0
        }
        LocalDate.parse(formatDate(firstEntry.timestamp), DateTimeFormatter.ISO_LOCAL_DATE)
            .minusDays(1)  // 从首条记录的次日开始
    } else {
        LocalDate.parse(settings.lastDecayDate)
    }
    
    val todayDate = LocalDate.parse(today)
    val daysToCatchUp = ChronoUnit.DAYS.between(lastDate, todayDate).toInt()
    if (daysToCatchUp <= 0) return 0
    
    var totalDeducted = 0f
    var currentScore = settings.totalScore
    var currentDate = lastDate.plusDays(1)
    
    repeat(daysToCatchUp) {
        val rank = getRank(currentScore)
        val deduction = getDecayAmountForRank(rank, settings.rankDecayAmounts)
        if (deduction > 0f) {
            currentScore = roundToOneDecimal(currentScore - deduction)
            totalDeducted += deduction
            // 添加历史记录
            historyDao.insertEntry(
                HistoryEntryEntity(
                    timestamp = currentDate.atStartOfDay(ZoneId.systemDefault()).toInstant().toEpochMilli(),
                    delta = -deduction,
                    event = "业力衰减",
                    type = "decay",
                    totalAfter = currentScore,
                )
            )
        }
        currentDate = currentDate.plusDays(1)
    }
    
    // 更新总分和 lastDecayDate
    settingsDao.upsertSettings(settings.copy(
        totalScore = currentScore,
        lastDecayDate = today,
    ))
    
    return totalDeducted
}
```

### 3.3 阶位判定函数

```kotlin
private fun getRank(score: Float): Int {
    return when {
        score < 0 -> 0        // 无阶位，按一阶处理
        score < 10 -> 1
        score < 30 -> 2
        score < 60 -> 3
        score < 100 -> 4
        score < 150 -> 5
        score < 210 -> 6
        score < 280 -> 7
        score < 360 -> 8
        else -> 9
    }
}

private fun getDecayAmountForRank(rank: Int, amounts: List<Float>): Float {
    if (amounts.isEmpty()) return 2f  // 默认值
    val index = (rank - 1).coerceIn(0, amounts.size - 1)
    return amounts[index]
}
```

### 3.4 历史记录中衰减的展示

- `type = "decay"` 的条目在历史图表中正常显示为数据点
- 工具弹窗中 event 显示 "业力衰减"，delta 显示扣除值（红字负值）
- 历史筛选（日/周/月/全部）同样包含衰减记录

### 当前问题

- WEEK 和 MONTH 模式下每组只取**最后一条**，而非全部记录
- 缺少"全部"模式

### 改造方案

#### 1. ViewMode 扩展
```kotlin
enum class ViewMode {
    DAY, WEEK, MONTH, ALL
}
```

#### 2. HistoryViewModel.aggregate() 重写

```kotlin
private fun aggregate(entries: List<HistoryEntryEntity>, mode: ViewMode): List<AggregatedPoint> {
    if (entries.isEmpty()) return emptyList()
    val now = System.currentTimeMillis()
    val cal = Calendar.getInstance()
    
    return when (mode) {
        ViewMode.DAY -> {
            cal.timeInMillis = now
            cal.set(Calendar.HOUR_OF_DAY, 0)
            cal.set(Calendar.MINUTE, 0)
            cal.set(Calendar.SECOND, 0)
            cal.set(Calendar.MILLISECOND, 0)
            val todayStart = cal.timeInMillis
            entries.filter { it.timestamp >= todayStart }.map { it.toAggregated() }
        }
        ViewMode.WEEK -> {
            val weekAgo = now - 7 * 24 * 60 * 60 * 1000L
            entries.filter { it.timestamp >= weekAgo }.map { it.toAggregated() }
        }
        ViewMode.MONTH -> {
            val monthAgo = now - 30 * 24 * 60 * 60 * 1000L
            entries.filter { it.timestamp >= monthAgo }.map { it.toAggregated() }
        }
        ViewMode.ALL -> entries.map { it.toAggregated() }
    }
}
```
