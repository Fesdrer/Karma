# 🧘 Karma — 业力值模拟器

记录每日善恶因果，见证业力流转。一款以业力为主题的生活记录与可视化工具。

> **版本**：4.3 | **技术栈**：Kotlin + Jetpack Compose + Material3 + Room | **最低 SDK**：Android 7.0

---

## 🚀 快速上手 — 30 秒学会怎么用

打开应用，你会看到一个三栏布局的主屏幕：

```
┌─────────────────────────────────────────┐
│  总分: 15.5     [叁阶]                   │  ← Header：总分 + 阶位
│  运气 +12.50                              │  ← 运气增幅值（若启用）
├────────┬──────────────┬──────────────────┤
│ 左栏   │   中栏       │     右栏         │
│ 分数   │   业力轴     │     事件         │
| [分数] |              |                 |  ← 当前选中分数
│ -6 ◀───│   ┌────┐    │   ── 善业 ──     │
│ -5     │   │壹阶│    │   帮助他人 ✔     │
│ ...    │   │贰阶│    │   早起早睡       │
│ +6     │   └────┘    │   ── 恶业 ──     │
│ [输入] │   ◀──▶      │   发脾气         │
│ 自定义 │   刻度值     │   浪费粮食       │
│ ×1/7   │             │   ── 善果 ──      │
│ ×2     │             │   ...             │
│ [重置] │             │  ▶ 开始计时 +1.5  │  ← 计时按钮
├────────┴──────────────┴──────────────────┤
│ [誓约][自证][祈福][确认][占卜][历史][⚙] │
└─────────────────────────────────────────┘
```

| 步骤 | 操作 | 位置 |
|:---:|------|------|
| **①** | **选分数** — 点击左栏刻度上的数值，或底部输入自定义数字 | ← 左栏 |
| **②** | **选事件** — 点击右栏中的某个事件标签（善业/恶业/善果）；选择后左侧分数栏**自动移到该事件的默认分数**（可在设置页修改），之后仍可滑动调整 | → 右栏 |
| **③** | **即时记录** — 底部「确认」按钮亮起后点击，即完成一次记录 | ↓ 底部 |
| **④** | **计时记录** — 点击右栏底部「▶ 开始计时」，右栏底部展开为计时控制栏，时间越长分数越高，停止后自动记录 | → 右栏底部 |

> ③④ 二选一：即时记录适合固定分数场景，计时记录适合按时间累积分数的场景。

> 💡 左栏当前选中分数始终显示（默认 0），正分绿色、负分红色、零分蓝色。
> 💡 v3.13 起：每个事件可配置**默认分数**（设置页·事件管理），主页面点选事件即自动带分；善业为正、恶业/善果为负（默认 ±1）。
> 💡 v4.1 起：左栏底部**乘法按钮**支持**分配律多选**——点击乘数仅切换选中（分数不变，选中金色高亮，再按一次取消，可多选多个），按主页面「确认」记录时应用 `本次分数 = 当前分数 × Σ(选中乘数)`（四舍五入到 0.5，如 +3 选 ×1 与 ×1/3 → +4）；倍率支持分数输入（如 1/7）。
> 💡 v4.3 起：左栏最下方新增**「重置」按钮**——一点即把当前选中的加减分归 0、事件取消选中、乘法按钮取消选中（不影响业力总分）。

**例如**：

```
善行场景：今天我帮了同事一个忙，想记 +2 分
```

1. **选分数** → 在左栏点击 `+2`（分数自动变红色高亮，顶部显示 "+2"）
2. **选事件** → 在右栏"善业"区域点击「帮助他人」（事件自动加金色边框）
3. **点确认** → 底部「确认」按钮变蓝，点击
4. 观察结果：Header 总分增加、业力轴指针滑动、历史图表新增一个点

### 记录一次恶行

```
场景：今天发脾气了，想记 -1.5 分
```

1. **选分数** → 在左栏点击 `-1.5`
2. **选事件** → 在右栏"恶业"区域点击「发脾气」
3. **点确认**

### 输入自定义分数或事件

- **自定义分数**：左栏底部的输入框直接输入数字（如 `3.5`），优先级高于点击选择
- **自定义事件**：每个事件分类（善业/恶业/善果）下方各有独立输入框，输入的文字会跟随对应的分类记录
- 善果事件自动加"善果："前缀，祈福事件自动加"祈福："前缀（与具体内容换行分隔）

### 使用计时记录

```
场景：今天打坐了，想按时间每小时 +2 分
```

1. **选分数** → 在左栏点击 `+2`
2. **选事件** → 在右栏"善业"区域点击「打坐冥想」（或自定义输入）
3. **点计时** → 点击右栏底部「▶ 开始计时」，右栏底部展开为计时控制栏
4. 打坐过程中手机可熄屏，通知栏会显示计时进度
5. 打坐结束后（比如打坐 30 分钟）点击「停止」→ 自动计算 `30 / 60 × 2 = 1` → 四舍五入到最近 0.5 = **+1.0 分**，记录并返回主页

## 🧭 导航总览

底部按钮 + 右栏内嵌计时控制：

| 按钮 | 条件 | 用途 |
|:---:|:---:|:------|
| **确认** | 需同时选择分数和事件 | 提交本次业力变动（即时记录）；若左栏选中了乘数，按分配律应用 `分数 × Σ(选中乘数)` 后记录 |
| **▶ 开始计时** | 需同时选择分数和事件 | 右栏底部内嵌计时控制，正计时累计，暂停/继续，停止时按公式 `round(分钟/60×分数, 0.5)` 记录 |
| **祈福** | 总分 ≥ 30 分才可点击 | 消耗业力换取心愿，可换行输入祈福目的、神明与手绘神秘符号（开关控制，画作不入记录），伴随粒子动画 |
| **誓约** | 始终可用 | 立下对赌誓言（内容/期限/成功加分/失败减分），信守 ✔ 加分、违背 × 减分，点击行查看详情 |
| **自证** | 设置页开启后显示；距离下一正阶位不足 10 分时可点击 | 阶位自证：以起点阶位为基准，全程保持不降级直到时长结束，结束时阶位高于起点即成功（详见「阶位自证」） |
| **占卜** | 气运测试不限次；小六壬/大衍筮法受每日次数限制（每阶独立配置，默认 1~2 阶 0 次、3~5 阶 2 次、6 阶及以上 3 次），次数用完显示 🔒 锁定画面 | 三标签页：气运测试（随机概率）/ 大衍筮法（需输入事情+扣分）/ 小六壬（需输入事情+扣分），完成后自动记录；结果页末尾有「🤖 AI 分析」按钮，可把求占事项与结果发给大模型生成解读启示（需在设置页配置 API） |
| **历史** | 始终可用 | 折线图查看业力变化趋势（支持日期导航与缩放） |
| **⚙** | 始终可用 | 自定义所有设置项 |

> 页面切换动画：全部页面均为 250ms 淡入淡出。设置页 v3.12 起拆分为轻量分类入口页（根页只有多张卡片），不再需要像 v3.10 那样因整页过重而瞬间切换（详见版本记录 v3.12）。

## 🎯 核心功能

### ★ v3.6 视觉主题系统

应用采用暗色主题 + 可自定义的背景渐变 + 装饰星图叠加，所有页面统一衬线字体（思源宋体）：

- **背景结构**（z-order）：`垂直渐变层 → 内容区 → 星星装饰图（FillBounds 全屏）`
- **渐变**：设置页可自定义起始色（顶部）和结束色（底部），默认深蓝灰 → 暗褐（天地玄黄）
- **配色**：全局暗色 Gold 主题，UI 组件统一金色边框（Gold 描边 + 圆角卡片）
- **字体**：全局 `FontFamily.Serif`（Canvas Paint 同步 `Typeface.SERIF`）

### 阶位晋升 & 业力衰减

阶位完全可自定义（名称/颜色/分数上限/衰减量/数量均可自由调整），默认配置如下：

在设置中开启业力衰减后，每天固定时间自动扣分：

- 应用**每次启动**时检查并补扣遗漏天数
- 应用运行期间每 **2 秒**周期判定一次（v4.2 起）：进程存活时（含计时/自证中）跨过衰减时刻立即补扣，不再依赖重启
- 默认扣除时间：23:00
- 各阶位扣除量可在设置中单独调整

总分达到特定门槛即可晋升阶位，阶位越高每日自然衰减越多（以下为默认值）：

| 阶位 | 分数 | 颜色 | 日衰减 |
|:---:|:---:|:---:|:---:|
| 壹阶 | 0~10 | 🔵 | 2分 |
| 贰阶 | 10~30 | 🔵 | 2分 |
| 叁阶 | 30~60 | 🔵 | 2分 |
| 肆阶 | 60~100 | 🔵 | 2分 |
| 伍阶 | 100~150 | 🟢 | 2分 |
| 陆阶 | 150~210 | 🟢 | 3分 |
| 柒阶 | 210~280 | 🟡 | 3分 |
| 捌阶 | 280~360 | 🟠 | 3分 |
| 玖阶 | **360+** | 🔴 | 3分 |

> 💡 业力为负时进入**负数阶位**（详见下方「负数阶位系统」）。

### 负数阶位系统（★ v3.11 新增）

业力为负时不再无阶位，而是落入负数阶位（默认 -1 微愆 → -9 无间，每 10 分一级，可增删/改名/改色/改下限）：

- **默认配置**：阈值 -10/-20/-30/-40/-50/-60/-70/-80 划分 -1~-9 级；颜色为渐变（-1 级 (80,80,80) 灰 → -9 级 (0,0,0) 黑，每级递减 10）
- **颜色三处同步**：主屏业力轴负数区域色带、历史图负数区域色带、Header 阶位徽章（负阶徽章纯色不透明显示），均跟随设置页负阶颜色
- **与正阶同构**：每阶一个设置框（名称/颜色/下限/占卜次数），支持 +/− 增删（插入自动取阈值中点），下限即本级业力下限（最深一级无下限，-∞）
- **占卜次数**：负阶默认全部 0 次（业力为负不能占卜）
- **业力衰减**：业力 ≤ 0 时不衰减（衰减不作用在负业力上）

### 阶位自证（★ v4.0 新增）

**配得上这个阶位吗？** 自证考验"上去的能力 + 保持的能力"：既要在时长内不掉下去，也要在结束时仍高于起点阶位。业力衰减正是自证的试金石——所以自证时长必须覆盖衰减时刻（v4.2 起衰减在运行期间每 2 秒周期判定，自证途中跨过衰减时刻会被真实扣分，跌破起点即失败）。

- 设置页开启「自证」后，主页面底部出现**自证按钮**（红色，与祈福金色区分）
- **主动自证**：距离下一正阶位不足 10 分时可按下开启；**被动自证**：**任何加分**（普通记录、计时结算、誓约了结加分等）跨入更高正阶位时自动弹出询问（可设自证或逃避扣分退回）
- 起点阶位 x：主动=自证开始时的阶位；被动=**加分前**的阶位
- 规则：
  1. 整个时长内，任何时刻阶位低于 x → 立即失败
  2. 时长结束时，当前阶位 y > x → 成功（恭喜登上 y）；否则失败
- 时长 0~24 小时（时:分滚轮），可设成功奖励分 / 失败惩罚分；衰减开启时必须覆盖下一次衰减时刻
- 自证期间数轴显示**渐变亮斑线**（线色→白色→线色的波形从下往上流动）+ 倒计时矩形（替换红点），徽章停留在起点阶位
- 自证状态持久化到数据库，应用被杀/重启后自动恢复判定
- 设置页「自证」分类可调 6 个特效颜色（数轴粗线 / 光晕粒子 / 倒计时背景与文字 / 成功 / 失败弹窗主色）

### 乘法功能（★ v4.0 新增，v4.1 分配律交互）

左栏分数栏底部新增**乘法按钮列**（默认 ×1/7、×2 等，可在设置页·乘法功能增删改）：

- v4.1 起为**分配律交互**：点击乘数按钮仅**切换选中状态**（当前分数不变，选中按钮金色高亮，再按一次取消，可多选多个），不再点击立即乘算
- 按主页面**「确认」**记录时一次性应用：`本次记录分数 = 当前分数 × Σ(选中乘数)`，结果四舍五入到 0.5（如 +3 选 ×1 与 ×1/3 → +4）；记录后自动清空乘数选中
- 倍率支持分数输入（如 1/7），存为分数类（Fraction）显示，不会变成小数
- 与滑动选分、自定义输入共存：确认时基于当前选中分数计算

### 祈福（消耗业力）

总分 ≥ 30 分时可进入祈福页面。输入扣减分数和祈福目的（支持多行输入），可开启「添加神明」开关额外输入神明名称，可开启「绘制神秘符号」开关用手绘画板绘制神秘学符号（v4.2 新增），点击确认后：

- 分数被扣除，记录格式为"祈福：+ 换行 + 目的内容 + 换行 + 神明：+ 换行 + 神明名称"（**画作不入记录**，仅本次祈福自赏，不持久化）
- 触发**粒子特效动画**（等级越高效果越华丽），动画中祈福文字为纯红色
- 输入框装饰括号「左上角 / 右下角」对角布局
- 最高阶可达"神圣"级：金色光环 + 符文粒子飞舞 🏆

### 占卜（判断运势）

底部三标签切换：

- **气运测试**（tab 0）：免费且不限次数，无需输入和扣除分数，直接点击「开始」→ 在后台协程中模拟 1000 次随机抛硬币（49% 正面概率），不阻塞 UI，显示正面次数。**v4.3 起带冷却时间**（默认 1.5 秒，可在「设置 → 占卜」调整）：点击后按钮置灰并禁用，底色由左到右逐渐恢复，恢复后才能再点
- **大衍筮法**（tab 1）：受**每日占卜次数限制**（每阶独立配置，默认 1~2 阶 0 次、3~5 阶 2 次、6 阶及以上 3 次，气运测试不计入），次数用完显示 🔒 锁定画面；进入前须输入占卜事情和扣除业力分数。最古老的周易起卦方法（揲蓍法），以 50 根翠绿策棒模拟天地运行，经 18 变（6 爻 × 3 变）得出本卦与变卦。完成后展示四块启示：本卦｜变卦（Canvas 手绘六爻+阴阳线）、卦象总纲、六爻精解（动爻标 ★ 高亮）、变卦指向总结。卦库含 64 卦完整启示 + 体用生克合解引擎，采用 load/release 模式。占卜完成后自动记录扣分到历史，点击「再来一次」重新弹出输入框
- **小六壬**（tab 2）：同样受**每日占卜次数限制**（与大衍筮法共享同一额度），进入前须输入占卜事情和扣除业力分数。传统掌诀占卜（马前课），以月、日、时辰在手掌六宫上掐指推算吉凶。输入支持传统农历和任意数字双模式，动画采用移动光点+虚幻拖尾沿六宫路径游走，最终展示古卷轴风格结果卡（宫名/吉凶/五行/六神/口诀/五项启示）。占卜完成后自动记录扣分到历史，点击「再来一次」重新弹出输入框
- **AI 分析（★ v4.1 新增）**：大衍筮法与小六壬结果页末尾新增「🤖 AI 分析」按钮，点击后把**求占事项 + 完整占卜结果**（大衍：本卦/卦象总纲/六爻精解/变卦/能量趋势；小六壬：宫位吉凶/五行方位六神/五项启示/口诀）发送到大模型（OpenAI 兼容接口，如 DeepSeek），返回针对性解读与启示（当前状况/吉凶趋势/行动建议/注意事项）。首次使用前需在「设置 → AI 分析」配置 API 地址、Key 与模型名（模型名区分大小写，DeepSeek 为 `deepseek-v4-flash` 或 `deepseek-chat`）
- 输入窗口（占卜/祈福）超高时**窗口内部滚动**，确认按钮始终可达；输入框内部可上下滑动

### 誓约（★ v3.10 新增，v4.3 终止时间与到期判定）

底部「祈福」与「占卜」之间的「誓约」入口。立下对赌誓言，信守加分、违背减分：

- 右上角「+」填写四项：对赌内容、**终止时间**（v4.3 起改为滚轮选择：第一行 年/月/日、第二行 时/分/秒，默认当前时间；不合法日期如 2 月 30 日会提示错误）、成功加分、失败减分（填正数，失败时扣除）
- 点「确定」：历史新增 `誓约：内容/终止时间/+加分/-减分` 四行记录（分数不变），誓约进入进行中列表
- **到期判定（v4.3）**：与业力衰减/每日必做一起在运行期间每 2 秒判定（打开应用时立即判定一次）；到期后在**首页弹窗**询问「是否完成」——「完成」加成功分、「未完成」扣失败分，两种情况都移除该誓约
- 列表每行有独立 ✔（成功 → 总分加成功分）和 ×（失败 → 总分减失败分）按钮，了结后该誓约从列表消失
- 点击誓约行 → 详情弹窗查看完整信息（含终止时间、立誓时间）；不支持中途撤销
- 数据存于 settings 的 JSON 列，随 JSON 导出/导入自动备份（v4.3 升级时旧版文本期限的誓约会被清空）

### 运气增幅（★ v3.5 新增）

业力对运气的影响不仅看总业力，还看近期行为导致的业力波动：

- 在设置中开启后，主页 Header 总分下方显示运气增幅值
- 三个可调参数：T（影响天数）、b（好事基准分）、W（波动权重）
- 近期行善 → 运气上升；近期作恶 → 运气下降
- 公式 `(K + c·∫K'·e^{-at²}dt) / b`，其中积分利用 erf 函数精确计算
- 计算已从主屏 combine 热路径中分离（debounce 300ms），避免每次记录后重计算阻塞 UI

### 每日必做（★ v3.7 新增）

在设置页「每日必做」卡片中，可将善业设为每日必做并设置未完成扣分：

- 勾选后该善业在主页右栏显示为蓝色（未做），完成确认后变绿色（已做）
- 未完成的每日必做会在业力衰减补扣时自动扣除设定分数，历史记录为"未完成：{事件名}"（v4.2 起衰减运行期间每 2 秒周期判定，跨过时刻即自动补扣并重置 vis，不必等重启）
- 保存设置时若必做配置有变动，所有 vis 重置为 0（新的一天）
- 导出/导入 JSON 时包含全部每日必做配置，导入后 vis 自动归零
- **桌面组件**（v4.3）：手机桌面可添加 2×2 组件（EMUI 中叫「窗口小工具 / 服务卡片」），列出今日**未完成**的每日必做，每行前面一个圆圈；点圆圈即视为完成——组件直接写库（标记完成 + 按该善业的默认分加分 + 写一条历史记录），该行随即从组件消失，**不打开 App**；**仅当这次加分跨入更高正阶位时**才打开 App 弹自证窗；条目多时可上下滚动，全部完成时显示「今日必做已全部完成」

### 计时记录（★ v3.4 新增，v3.7 内嵌改造，v3.8 崩溃恢复）

在右栏底部点击「▶ 开始计时」，按钮原地展开为计时控制栏：

- **正计时**：时间从 00:00:00 开始递增，21sp 金色数字显示
- **暂停 / 继续**：随时暂停后恢复，不影响累计时间（#b8860b 暗金色按钮）
- **熄屏继续**：计时期间即使手机熄屏，后台前台服务继续计时，通知栏显示实时时间
- **自由切换**：计时可随时点击 Footer 切换到设置/历史等页面，返回后时间正确显示
- **崩溃恢复**：计时状态持久化到 Room 数据库，应用被系统杀死或崩溃后重启，自动恢复计时；**v4.3 起改用墙钟时间戳（System.currentTimeMillis）持久化**，手机重启后已计时长同样连续（修复此前"过去 3 小时只剩 7 秒"）
- **分数计算**：停止时按公式 `round(已计时分钟数 / 60 × 所选分数, 0.5)` 自动计算 delta 并写入数据库
- **记录信息**：事件 = 所选事件，时间戳 = 停止时刻，type = "record"

> 💡 适合需要按实际耗时累计业力的场景，如"打坐 30 分钟 +2 分"、"刷手机 1 小时 -4 分"等。

## 📊 历史记录

点击底部「历史」进入。页面支持五种交互功能：

### 视图切换

左上角下拉菜单切换四种时间范围：

| 视图 | 范围 | 使用场景 |
|:---:|:---|:---|
| **日** | 聚焦某一天 | 查看当天细粒度变化 |
| **周** | 聚焦某一周 | 本周趋势分析 |
| **月** | 聚焦某个月 | 中期走势观察 |
| **全部** | 所有数据 | 完整回顾 |

### 日期导航

◀ 和 ▶ 按钮逐日/逐周/逐月前后翻看，[今天] 一键回到当前周期，▶ 到达最新日期后自动置灰。

### 缩放钻取

**[放大]** 进入缩放模式，点击图表数据点下钻到更细粒度；**[缩小]** 反向操作回到粗粒度：

| 按钮 | 日视图 | 周视图 | 月视图 | 全部 |
|:---:|:---:|:---:|:---:|:---:|
| **放大** | 禁用 | 钻取到日 | 钻取到周 | 钻取到月 |
| **缩小** | 回到周 | 回到月 | 回到全部 | 禁用 |

钻取到日视图后自动退出缩放模式。周标签格式为完整年份（如 `2025/6/7-2025/6/13`）。

### 图表交互

- **点击数据点**：弹出自适应定位浮层（四向翻转不超出屏幕），显示时间、变动值、事件和总分
- **长事件名**：浮层内自动换行，不受行数限制
- **阶位色带**：图表背景中阶位半透明色带，正阶与负数阶位均有，跟随自定义阶位设置动态变化
- **缩放模式**：点击数据点直接下钻到更细粒度

### 数据管理

右端 **导出 ▼** 下拉菜单（与视图模式同排）支持：

- **CSV 导出** — 表格格式，可用 Excel 打开（仅历史记录）
- **JSON 导出** — 结构化数据（**v2 格式**），**包含全部设置项**（颜色、字体、衰减参数、阶位配置、负阶配置、占卜次数、事件预设、事件默认分数、运气参数、乘法按钮、自证配置等）+ 历史记录
- **导入** — 恢复导出的 JSON 或 CSV 数据；JSON 校验 `version: 2`，**旧版本格式直接拒绝**（v3.11 起不兼容旧版 JSON）；v4.0 起对缺字段 JSON 逐字段兜底（乘法乘数、自证 14 个字段缺键时补默认值，不再导入失败）
- v4.1 起 **AI 分析配置**（API 地址/Key/模型）存于本机 SharedPreferences（`ai_config`），**不随 JSON 导出**（换机/重装后需在设置页重新填写；JSON 格式与旧版本完全兼容）
