# 🧘 Karma — 业力值模拟器

记录每日善恶因果，见证业力流转。一款以业力为主题的生活记录与可视化工具。

> **版本**：3.2 | **技术栈**：Kotlin + Jetpack Compose + Material3 + Room | **最低 SDK**：Android 7.0

## 🚀 快速上手 — 30 秒学会怎么用

打开应用，你会看到一个三栏布局的主屏幕：

```
┌─────────────────────────────────────────┐
│  总分: 15.5     [叁阶]                   │  ← Header：总分 + 阶位
├────────┬──────────────┬──────────────────┤
│ 左栏   │   中栏       │     右栏         │
│ 分数   │   业力轴     │     事件         │
| [分数] |              |                 |  ← 当前选中分数
│ -6 ◀───│   ┌────┐    │   ── 善业 ──     │
│ -5     │   │壹阶│    │   帮助他人 ✔     │
│ ...    │   │贰阶│    │   早起早睡       │
│ +6     │   └────┘    │   ── 恶业 ──     │
│ [输入] │   ◀──▶      │   发脾气         │
│ 自定义 │   指引线     │   浪费粮食       │
├────────┴──────────────┴──────────────────┤
│  [确认]  [祈福]  [占卜]  [历史]  [⚙]     │
└─────────────────────────────────────────┘
```

| 步骤 | 操作 | 位置 |
|:---:|------|------|
| **①** | **选分数** — 点击左栏刻度上的数值，或底部输入自定义数字 | ← 左栏 |
| **②** | **选事件** — 点击右栏中的某个事件标签（善业/恶业/善果） | → 右栏 |
| **③** | **点确认** — 底部「确认」按钮亮起后点击，即完成一次记录 | ↓ 底部 |

> 完成三步后，总分自动更新，业力轴上的指针会动画滑动到新位置 ✅

> 💡 左栏当前选中分数始终显示（默认 0），正分绿色、负分红色、零分蓝色。

**例如**：

```
善行场景：今天我帮了同事一个忙，想记 +2 分
```

1. **选分数** → 在左栏点击 `+2`（分数自动变红色高亮，顶部显示 "+2"）
2. **选事件** → 在右栏"善业"区域点击「帮助他人」（事件自动加金色边框）
3. **点确认** → 底部「确认」按钮变蓝，点击
4. 观察结果：Header 总分增加、业力轴指针滑动、历史图表新增一个点

### 记录一次恶行

```
场景：今天发脾气了，想记 -1.5 分
```

1. **选分数** → 在左栏点击 `-1.5`
2. **选事件** → 在右栏"恶业"区域点击「发脾气」
3. **点确认**

### 输入自定义分数或事件

- **自定义分数**：左栏底部的输入框直接输入数字（如 `3.5`），优先级高于点击选择
- **自定义事件**：每个事件分类（善业/恶业/善果）下方各有独立输入框，输入的文字会跟随对应的分类记录
- 善果事件自动加"善果："前缀，祈福事件自动加"祈福："前缀（与具体内容换行分隔）

## 🎯 核心功能

### 阶位晋升&业力衰减

**★ v3.2 新增**：阶位完全可自定义（名称/颜色/分数上限/衰减量/数量均可自由调整），默认配置如下：

在设置中开启业力衰减后，每天固定时间自动扣分：

- 应用**每次启动**时检查并补扣遗漏天数
- 默认扣除时间：23:00
- 各阶位扣除量可在设置中单独调整

总分达到特定门槛即可晋升阶位，阶位越高每日自然衰减越多（以下为默认值）：

| 阶位 | 分数 | 颜色 | 日衰减 |
|:---:|:---:|:---:|:---:|
| 壹阶 | 0~10 | 🔵 | 2分 |
| 贰阶 | 10~30 | 🔵 | 2分 |
| 叁阶 | 30~60 | 🔵 | 2分 |
| 肆阶 | 60~100 | 🔵 | 2分 |
| 伍阶 | 100~150 | 🟢 | 2分 |
| 陆阶 | 150~210 | 🟢 | 3分 |
| 柒阶 | 210~280 | 🟡 | 3分 |
| 捌阶 | 280~360 | 🟠 | 3分 |
| 玖阶 | **360+** | 🔴 | 3分 |

> 💡 负数不归属任何阶位，显示「—」。

### 祈福（消耗业力）

总分 ≥ 30 分时可进入祈福页面。输入扣减分数和祈福目的（支持多行输入），点击确认后：

- 分数被扣除，记录为"祈福：+ 换行 + 目的内容"
- 触发**粒子特效动画**（等级越高效果越华丽）
- 输入框装饰括号「左上角 / 右下角」对角布局
- 最高阶可达"神圣"级：金色光环 + 符文粒子飞舞 🏆

### 占卜（判断运势）

底部三标签切换：
- **气运测试**：点击「开始」→ 模拟 1000 次随机抛硬币（49% 正面概率），显示正面次数
- **大衍筮法**、**小六壬**：预留功能，即将推出

## 📊 历史记录

点击底部「历史」进入。页面支持五种交互功能：

### 视图切换

左上角下拉菜单切换四种时间范围：

| 视图 | 范围 | 使用场景 |
|:---:|:---|:---|
| **日** | 聚焦某一天 | 查看当天细粒度变化 |
| **周** | 聚焦某一周 | 本周趋势分析 |
| **月** | 聚焦某个月 | 中期走势观察 |
| **全部** | 所有数据 | 完整回顾 |

### 日期导航

◀ 和 ▶ 按钮逐日/逐周/逐月前后翻看，[今天] 一键回到当前周期，▶ 到达最新日期后自动置灰。

### 缩放钻取

**[放大]** 进入缩放模式，点击图表数据点下钻到更细粒度；**[缩小]** 反向操作回到粗粒度：

| 按钮 | 日视图 | 周视图 | 月视图 | 全部 |
|:---:|:---:|:---:|:---:|:---:|
| **放大** | 禁用 | 钻取到日 | 钻取到周 | 钻取到月 |
| **缩小** | 回到周 | 回到月 | 回到全部 | 禁用 |

钻取到日视图后自动退出缩放模式。周标签格式为完整年份（如 `2025/6/7-2025/6/13`）。

### 图表交互

- **点击数据点**：弹出自适应定位浮层（四向翻转不超出屏幕），显示时间、变动值、事件和总分
- **长事件名**：浮层内自动换行，不受行数限制
- **阶位色带**：图表背景中阶位半透明色带，跟随自定义阶位设置动态变化
- **缩放模式**：点击数据点直接下钻到更细粒度

### 数据管理

右端 **导出 ▼** 下拉菜单（与视图模式同排）支持：

- CSV 导出 — 表格格式，可用 Excel 打开
- JSON 导出 — 结构化数据
- 导入 — 恢复之前导出的数据

## 🏗️ 技术架构（开发者向）

```
Kotlin + Jetpack Compose
├── UI Layer     → 5个 Compose Screen（主屏/历史/祈福/占卜/设置）
├── ViewModel    → MainVM / HistoryVM / PrayerVM / SettingsVM
├── Repository   → KarmaRepository（业务逻辑 + 数据聚合）
├── Data Layer   → Room (HistoryEntry + KarmaSettings, 2 DAO)
└── DI           → AppContainer（手动依赖注入）
```

### 技术亮点

- **纯 Canvas 渲染**：分数轴、业力轴、折线图、粒子动画全部手绘，零第三方图表依赖
- **非线性映射**：业力轴采用动态指数算法，`y ∝ x^exp`，exp 由 quarterValue 自动推导
- **粒子引擎**：4 级粒子系统，含 Bezier 曲线、光环、火花、符文
- **衰减追溯**：启动时自动补扣遗漏天数，支持算法回溯
- **Flow 状态管理**：利用 Kotlin Flow combine 管理多数据源状态同步，解决 6+ 流类型推断限制
